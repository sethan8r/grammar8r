# grammar-app-ios

Место под будущее iOS-приложение Grammar8r. Сейчас пусто — разработка под iOS не начата.

## Что здесь будет

- Xcode-проект: SwiftUI-экраны, навигация, iOS-реализации репозиториев (хранилище прогресса, сеть,
  настройки), интеграции (StoreKit/оплата, APNs, вход).
- Логику здесь не пишем: модели, интерфейсы репозиториев и юзкейсы берутся из `grammar-core`,
  собранного в `XCFramework`.

## Чем эта папка отличается от остальных модулей

Это **не Gradle-модуль**: её нет в `settings.gradle.kts`, Gradle её не собирает. Xcode-проект
создаётся на Mac и подключает фреймворк, который Gradle собирает из `grammar-core`. Связь
односторонняя: `grammar-core` ничего не знает об iOS.

Собрать iOS-приложение можно только на macOS (Xcode существует только там).
