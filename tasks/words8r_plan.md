# Words8r — План улучшений

> Связанные планы: [grammar8r_plan.md](grammar8r_plan.md) | [development_plan.md](phases/development_plan.md)

Этот файл описывает что нужно добавить в Words8r для интеграции с Grammar8r.
Words8r — отдельный проект, не трогаем его архитектуру глобально, только добавляем нужное.

---

## 1. ContentProvider — отдать слова в Grammar8r

**Зачем:** Grammar8r использует известные слова пользователя для генерации AI-упражнений.
Подробно: [grammar8r_plan.md → Синхронизация с Words8r](grammar8r_plan.md#синхронизация-с-words8r)

**Что делать:**
- Добавить `WordsProvider : ContentProvider` в Words8r
- Зарегистрировать в `AndroidManifest.xml` с `android:exported="true"`
- URI чтения: `content://dev.sethan8r.sethanwords.provider/words`
- Опционально фильтр по уровню: `content://dev.sethan8r.sethanwords.provider/words?level=A1`
- Возвращает: `word`, `translation`, `transcription`, `level`
- Не ломает архитектуру — просто читает из существующей БД

## 2. Кнопка "Учить для Grammar8r" + приоритет слов

### Вторая кнопка "Учить"

На главном экране Words8r появляется вторая кнопка рядом с существующей "Учить слова":

| Кнопка | Что тянет |
|--------|-----------|
| **"Учить слова"** (существующая) | Только обычные категории пользователя — без Grammar8r категорий |
| **"Учить для Grammar8r"** (новая) | Только категории из Grammar8r: "Basic Verbs", "Verb Forms", "Grammar Basics", "Informal English" |

Grammar8r-категории **не появляются** в обычной кнопке "Учить слова" — естественная фильтрация по принадлежности к Grammar8r. Пользователь может включать/выключать отдельные Grammar8r-категории галочкой внутри новой кнопки.

Алгоритм выборки и вся логика обучения — **идентична** существующей кнопке. Просто другой фильтр по категориям.

### Приоритет слов (Grammar8r → Words8r)

Перед каждой темой в Grammar8r показывается вводная карточка со списком 10-20 глаголов, нужных для этой темы. Пользователь может нажать **"Повысить приоритет в Words8r"**.

**Логика приоритета:**

- В таблице `words` добавляется поле `is_priority: Boolean` (default false)
- При нажатии кнопки Grammar8r ставит `is_priority = true` на выбранные слова
- Кнопка "Учить для Grammar8r" отдаёт приоритетные слова **первыми**, остальные — после
- Если все приоритетные слова выучены (qRep > 0) — идут обычные слова из Grammar8r-категорий в обычном режиме

**В любой момент активен только один набор приоритетных слов.** При повышении приоритета новых слов:
1. Grammar8r проверяет: есть ли слова с `is_priority = true` и qRep = 0 (не выучены)
2. Если есть — показывает предупреждение: *"Ещё X слов из прошлой темы не выучено. Заменить приоритет?"*
3. При подтверждении — снимаем `is_priority` со старых, ставим на новые

## 3. Приём слов от Grammar8r

**Зачем:** Из Grammar8r можно добавить слово в Words8r двумя способами:
1. Тап на слово → попап перевода (через LingvoLive/Yandex API) → "В мои слова"
2. Завершил микротему → sync BottomSheet → слова темы → в категорию темы

Подробно: [phase2/phase2b_words_write.md](phases/phase2/phase2b_words_write.md)

**Что делать:**

- Добавить write-поддержку в ContentProvider:
  ```
  Принимает: { word, translations[], transcription, category }
  ```
- **Динамические категории:** Words8r не знает заранее какие категории придут. При получении слова — найти категорию по имени или создать новую.
- Слово может быть в нескольких категориях одновременно (добавлено через тап и через sync темы).

**Категории:**

| Категория | Когда создаётся | Источник | Попадает в кнопку |
|-----------|----------------|----------|-------------------|
| "Мои слова" | Уже существует в Words8r | Тап на слово → "В мои слова" | "Учить слова" (обычная) |
| "Basic Verbs" | При первом синке из подготовительной карточки Present Simple | 15-20 базовых глаголов V1 | "Учить для Grammar8r" |
| "Verb Forms" | При синке из темы "Глаголы: V1, V2, V3" | 200+ глаголов со всеми формами | "Учить для Grammar8r" |
| "Grammar Basics" | При первом Grammar8r-синке предтемы | Words8r sync после микротем "Основ" | "Учить для Grammar8r" |
| "Informal English" | При синке из темы "Разговорный английский" | Разговорные сокращения | "Учить для Grammar8r" |

Если слово уже есть в данной категории → игнорировать (не дублировать).

## 3. Режим изучения форм глаголов

**Зачем:** Пользователь учит формы неправильных глаголов в Words8r, а потом применяет знания
в Grammar8r (Режим 4 "Заполни форму глагола" и тема "Формы глаголов V1/V2/V3").
Подробно: [grammar8r_plan.md → Режим 4](grammar8r_plan.md#режим-4-заполни-форму-глагола)

### База данных

Новая таблица `IrregularVerb`:
| Поле | Тип | Описание |
|------|-----|----------|
| id | Int PK | |
| v1 | String | Базовая форма: "go" |
| v2 | String | Past Simple: "went" |
| v3 | String | Past Participle: "gone" |
| translation | String | Переводы глагола: "идти, ходить, пойти, пошёл, ушедший" |

**Переводы: один список на весь глагол** (не разбивать по формам).
Включаем 4–5 самых полезных вариантов: инфинитив + живые формы разных контекстов,
чтобы русскоязычный студент сразу чувствовал "окраску" слова.

> ⚠️ **Переводы для каждого глагола подбираются вручную при составлении базы.**
> Не брать всё что выдаёт переводчик — только самые частые и понятные.
> Максимум 4–5 штук. Пример: `go` → `идти, ходить, пойти, пошёл, ушедший`.

База глаголов засеивается из assets JSON при первом запуске.
Для правильных глаголов добавить поле `isRegular: Boolean`.
Правильные глаголы — не случайные, а самые частотные + те, что новички путают с неправильными.
Цель: научить пользователя распознавать тип глагола и применять правило.

**Неправильные:** ~200 глаголов из [monolithpl/verb.forms.dictionary](https://github.com/monolithpl/verb.forms.dictionary)
(Oxford + Longman, фильтруем те где V2 ≠ V1+"ed").
Топ-50 частотных берём из [kemitchell/english-irregular-verbs](https://github.com/kemitchell/english-irregular-verbs)
и показываем в первую очередь, остальные после.

> ⚠️ **Переводы подбираются вручную при создании seed JSON. Не автоматизировать.**
> На каждый глагол 4–5 переводов: инфинитив + живые формы разных контекстов.

**Правильные:** 55 глаголов (расчёт: 200 × 20/80 = 50, +5 запас). Самые частотные,
подобранные вручную — в том числе те, что новички путают с неправильными.
Соотношение в сессии: **80% неправильные / 20% правильные**.

Если правильные закончились (все быстро выведены из ротации), а неправильные ещё остались —
сессия идёт 100% неправильными, ничего не сообщаем.

Повторение работает бесконечно — пока есть карточки с подошедшим интервалом, как обычные слова.
Поздравление "вы изучили все глаголы" показывается только на экране **новых** глаголов,
когда в очереди на изучение не осталось ни одного.

Таблица прогресса `IrregularVerbProgress` (интервальные повторения — аналог обычных слов):
| Поле | Тип | Описание |
|------|-----|----------|
| verbId | Int FK | |
| nextReviewAt | Long | Unix timestamp следующего повторения |
| interval | Int | Текущий интервал повторения (дни) |
| status | Enum | NEW / LEARNING / REVIEW |

### Соотношение правильных и неправильных глаголов в сессии

В очереди учёбы и повторения: **70% неправильные / 30% правильные**.
Упор на неправильные, но правильные подмешиваются — чтобы пользователь учился
распознавать тип глагола, а не просто зубрил список.

Тип глагола пользователю заранее **не сообщается** — он должен сам определить.
Если написал V2/V3 по правилу "-ed" для правильного глагола → верно.
Если написал "-ed" для неправильного → ошибка.

Для правильных глаголов спейсед репетишн короче: они быстрее "выводятся из ротации",
потому что всё что нужно — понять что глагол правильный и применить правило.

### UI карточки учёбы / повторения — отображение форм

На карточке показываем просто метки **V1 / V2 / V3** без расшифровки.
Никаких "инфинитив", "прошедшее время", "причастие" прямо на карточке — это лишний шум,
теория есть в Grammar8r.

Кнопка **`!`** в углу экрана (та же самая что в экране повторения проблемных слов в Words8r —
используем идентичный UI-паттерн). По нажатию выезжает BottomSheet с короткой справкой:
```
V1 — базовая форма (I go every day)
V2 — Past Simple (I went yesterday)
V3 — Past Participle (I have gone / It was gone)
```
Кнопка присутствует как на экране учёбы новых глаголов, так и на экране повторения.

### Учёба (новые глаголы)

- Показывается карточка: V1 + переводы + все три формы сразу (V1 / V2 / V3)
- Для правильных: показываем V1 + переводы + результат (V2 = worked, V3 = worked)
- Пользователь изучает и сам решает когда готов: свайп "Знаю" / "Ещё раз"
- Нет автоматической проверки при просмотре — человек сам оценивает

### Повторение — режимы проверки

При открытии сессии повторения пользователь выбирает режим:

| Режим | Что проверяется | Ошибки |
|-------|----------------|--------|
| 1+2 | Дано V1 + перевод → ввести V2 | нет |
| 1+3 | Дано V1 + перевод → ввести V3 | нет |
| 1+2+3 | Дано V1 + перевод → ввести V2 и V3 | нет |
| Смешанный | Дано V1 + перевод → ввести V2 и V3 | да (3 попытки) |

В режимах 1+2 / 1+3 / 1+2+3 — нет попыток и штрафов: просто показываем ввод, пользователь проверяет себя сам.

В **Смешанном** режиме:
- 3 попытки на карточку
- Пустое поле = не считается ошибкой
- Неправильно заполненное поле = -1 попытка
- Баллы ошибок и "проблемные слова" — не реализовывать пока, разберёмся позже

### UI карточки повторения

Три варианта ответа (аналог обычных карточек):
1. **Ввод руками** — три поля "V1 форма", "V2 форма", "V3 форма"
   - Над каждым полем своя иконка `?` (подсказка для конкретного поля)
   - Кнопка "Проверить ответ" снизу (та же, что в обычных карточках)
2. **Классик** — показываем правильные формы, пользователь говорит знал/не знал
3. **2×2** — под каждым полем 4 варианта, выбрать правильный

В режимах 1+2 / 1+3 — показываем только нужные поля, остальные скрыты.
В режиме 1+2+3 / Смешанный — все три поля.

### Подсказка `?` над полем

Раскрывает подсказку только для конкретной формы:
- `?` над V2 → показывает правильный V2
- `?` над V3 → показывает правильный V3
- Используется лимит подсказок (аналог обычных карточек, если там есть лимит)

### Интеграция с Grammar8r

- В теме "Формы глаголов (V1/V2/V3)" в Grammar8r — кнопка "Перейти к изучению форм в Words8r" (Intent или deeplink)
- В Grammar8r Режим 4 — если пользователь ошибся в форме глагола, показать кнопку "Выучить этот глагол в Words8r"

## 4. Подписка — лимиты и интеграция с Grammar8r

**Зачем:** Words8r становится частью единой экосистемы. Подписка, купленная в любом из приложений (Grammar8r или Words8r), действует в обоих. Лимиты стимулируют покупку, не мешая обычному пользователю (5 слов в день — ниже лимита).

### Лимиты в Words8r

| Действие | Free | Tier 1 / Tier 2 |
|----------|------|-----------------|
| Новые слова/день | 10 | без лимита |
| Повторения/день | 50 | без лимита |
| Режим соответствия/день | 3 | без лимита |

Счётчики хранятся локально (Room), сбрасываются в 00:00 МСК — синхронно с Grammar8r.

### Логика проверки подписки (офлайн-first)

Words8r работает без интернета — подписка кэшируется локально.

**Правила:**

1. **Первый запуск приложения за день** → запрос к серверу `/subscription?uid=X`. Успешный ответ → кэшируем статус + timestamp.
2. **Никогда не было успешного ответа** (первая установка, нет интернета) → бесплатные лимиты.
3. **Есть кэш подписки + нет интернета** → доверяем кэшу. Подписка могла истечь, но не проверить — пользователь получает временный бонус, потери минимальны.
4. **Нет интернета > 7 дней с последнего успешного ответа** → при запуске показываем баннер: *"Не удалось проверить подписку — нет соединения. Установлены бесплатные лимиты."* Как только интернет появится и придёт ответ сервера — баннер пропадает.

**Тестовый режим:** константа `SUBSCRIPTION_GRACE_PERIOD` в одном месте. В дебаге = 10 минут, на проде = 7 дней. Не разбрасывать по коду.

### Покупка подписки в Words8r

- Экран подписки аналогичен Grammar8r (те же тиры, те же цены)
- YooKassa SDK + webhook на тот же сервер
- После успешной оплаты → форс-синк с сервером → лимиты сброшены немедленно
- Кнопка "Проверить подписку" (если купил в Grammar8r и хочет активировать в Words8r) → форс-синк

### Авторизация

Та же схема что в Grammar8r: Яндекс OAuth или email+пароль → uid → единый сервер подписок. Добавляется в Words8r параллельно с реализацией лимитов.

## Дизайн — изоляция

> ⚠️ **ВАЖНО: дизайн Words8r может смениться полностью.**
> Приложение несложное, переделать реально — но только если дизайн изолирован с самого начала.
> При любых правках в Words8r соблюдать:
> - цвета — только через тему/константы, не хардкодить в Composable
> - отступы и размеры — именованные константы, не `16.dp` прямо в коде
> - переиспользуемые элементы — вынесены отдельно, не дублируются по экранам
> - Composable-экраны — только UI, никакой логики
>
> Смена дизайна должна касаться только UI-слоя и не затрагивать логику приложения.
