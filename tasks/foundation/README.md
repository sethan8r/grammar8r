# tasks/foundation — пакет фундамента Grammar8r

Здесь живут документы первого шага разработки («Шаг 1. Фундамент приложения» из
`kickoff_context.md` §6): план фундамента, заметки для Fable и лог архитектурных решений.

## Зачем этот пакет существует

Контекст: 12.06.2026 правительство США директивой экспортного контроля приостановило доступ
к моделям **Fable 5 / Mythos 5** (см. `_self_prompt.md` → раздел «Откуда взялся этот пакет»).
По правилам проекта (`kickoff_context.md` §6.1) фундамент — архитектурно необратимый слой —
зарезервирован **только за Fable**. Fable временно недоступен на неопределённый срок, поэтому
принято решение: фундамент начинает делать **Opus**, но с защитными мерами, чтобы не
пожертвовать духом правил и дать Fable (когда вернётся) проверить необратимое одним проходом,
а не переразбираться с нуля.

## Файлы

| Файл | Назначение | Жизненный цикл |
|------|-----------|----------------|
| `foundation_plan.md` | Детальный план фундамента на ревью. Структура модулей, схема Room, контракты заглушек, сидинг, навигация. | Постоянный (обновляется по ходу) |
| `notes_for_fable.md` | Заметки для Fable: контекст решений, что Opus уже сделал, что помечено `provisional` и требует аудита. Чтобы Fable не ресёрчил с нуля. | Постоянный |
| `decision_log.md` | Лог архитектурных решений на «Fable-only» участке (схема Room, DTO-контракт). Заполняется ПО ХОДУ написания кода. | Постоянный |
| `_self_prompt.md` | Промт Claude (Opus) для себя самого: полный контекст этого чата и как пришли к выводу. Пользователь читает и удаляет. | **Временный — удалить после прочтения** |
