# Лог архитектурных решений — фундамент (Fable-only участок)

> **Назначение:** журнал необратимых решений, принятых Opus на участке, который по
> `kickoff_context.md` §6.1 зарезервирован за Fable. Чтобы Fable (когда вернётся) проверил их
> одним проходом, а не переразбирался с нуля.
> **Что сюда писать:** только 🟡 необратимое — схема Room (Entity, миграции, identity),
> DTO-контракт `grammar-shared`, границы слоёв. Обратимый каркас (🟢) сюда НЕ пишем.
> **Когда:** по ходу написания кода, сразу после принятия решения, не задним числом.

## Формат записи

```
### YYYY-MM-DD · <короткий заголовок решения>
- **Контекст:** что за задача, какой файл/таблица/DTO.
- **Варианты:** какие были (минимум 2 разумных).
- **Выбор:** что выбрал.
- **Почему:** аргумент (best practice / правило проекта / ограничение Room и т.п.).
- **Уверенность:** высокая / средняя / низкая — где низкая, Fable смотрит в первую очередь.
- **Обратимость:** как откатить, если Fable решит иначе.
```
