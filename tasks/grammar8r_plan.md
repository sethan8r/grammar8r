# Grammar8r — План проекта

## Общая идея

Два связанных Android-приложения:
- **Words8r** — уже существует, приложение для изучения слов
- **Grammar8r** — приложение для изучения английской грамматики

Grammar8r строится вокруг трёх вещей: **теория** (объяснения и примеры), **практика** (упражнения с AI на основе слов пользователя из Words8r) и **синхронизация словаря** между приложениями.

---

## Структура проекта

```
Grammar8r/
├── grammar-app/     ← Android-приложение
├── grammar-server/  ← Ktor backend (сервер подписок)
├── grammar-shared/  ← общие Kotlin-модели (SubscriptionStatus, UserInfo и т.д.)
└── settings.gradle.kts
```

**Words8r** остаётся отдельным проектом — не трогаем архитектуру.
Связь между приложениями только в **рантайме** через ContentProvider. Никакой build-time зависимости нет.

## Раздел "Теория"

### Структура контента

```
Теория
├── Предтема: "Основы"   ← идёт первой, особая категория
│   ├── Артикли (a, an, the, -)
│   ├── Предлоги места, времени, направления
│   ├── Личные и притяжательные местоимения
│   └── По окончании → предложение добавить базовый словарь в Words8r
│
├── Формы глаголов (V1/V2/V3)  ← вводная тема, идёт после "Основ" и до времён
│   ├── Что такое три формы глагола
│   ├── Неправильные глаголы: уникальные формы (go→went→gone) — нужно учить наизусть
│   ├── Правильные глаголы: V2 и V3 = V1 + "-ed" (+ правила написания)
│   ├── Примеры правильных глаголов с таблицей (work/play/stop/study и др.)
│   ├── Вывод: правильных тысячи — учим правило; неправильных ~200 — учим наизусть
│   └── Связь с Words8r: кнопка перейти в режим изучения форм глаголов
│       (см. tasks/words8r_plan.md → Режим изучения форм глаголов)
│
├── Present Simple
├── Present Continuous
├── Past Simple
├── Past Continuous
├── Present Perfect
├── Present Perfect Continuous
├── Past Perfect
├── Future Simple (will)
├── Future (going to)
├── Future Continuous
└── Future Perfect
```

### UX микротемы — пошаговые карточки

Каждая тема разбита на **микротемы**. Микротема — это последовательность шагов (карточек), а не один длинный экран. Пользователь листает кнопкой "Далее".

```
Шаг 1: Теория        ← короткий текст, одно правило, без скролла, дружелюбно
Шаг 2: Пример        ← одна пара RU → EN с пояснением
Шаг 3: Пример        ← ещё пара (если тема требует)
Шаг 4: Практика      ← расставить слова в правильном порядке (всегда бесплатно)
Шаг 5: Практика      ← ещё одно упражнение, чуть сложнее
Шаг 6: AI-практика   ← только при подписке / лимит 3/день
```

На карточках практики — иконка `?` в углу. Нажал → снизу выезжает BottomSheet с кратким конспектом правила (2–3 предложения).

### Расстановка слов (бесплатная практика)

- Карточки со словами перемешаны, нужно составить правильное предложение
- Нажатие на слово → маленький попап: перевод слова + кнопка "Добавить в Words8r"
- Переводы слов захардкожены в контенте (не требуют API)

### Прогресс

- На экране темы — прогресс-бар (X из N микротем пройдено)
- Микротема считается пройденной после выполнения практики
- На экране списка тем — прогресс виден сразу по каждой теме

### Предтема "Основы" — базовый словарь

Список ~60–80 слов захардкожен в assets: артикли, предлоги, местоимения, базовые глаголы. Каждое слово: `word`, `translation`, `transcription`.

После прохождения всех микротем предтемы — предложение добавить словарь в Words8r (категория "Grammar Basics"). Пользователь выбирает какие слова добавить.

## Раздел "Практика"

Три режима, все требуют подписки или входят в лимит 3 запросов/день.

### Режим 1: Упражнения по темам

- Пользователь выбирает темы и/или конкретные микротемы
- AI генерирует задание: перевести русское предложение на английский
- Слова для предложений берутся из Words8r (известные слова пользователя)
- AI проверяет ответ и возвращает фидбек:
  ```json
  { "isCorrect": bool, "correctedAnswer": "...", "feedback": "..." }
  ```
- `feedback` — конкретный разбор ошибки по-русски, 1–2 предложения. Без мотивации.

### Режим 4: Заполни форму глагола

- Дано русское предложение и его английский перевод, в котором один глагол стоит в скобках в форме V1
- Пользователь вписывает правильную форму глагола (регистр не важен)
- **Бесплатно:** захардкоженные упражнения из assets (не привязаны к конкретным временам — просто нужно определить нужную форму по контексту)
- **Подписка:** AI генерирует упражнения на основе слов пользователя из Words8r
- Тема пересекается с неправильными глаголами из Words8r (см. [tasks/words8r_plan.md](../words8r_plan.md))

Пример карточки:
```
RU: Он пришёл домой поздно.
EN: He (come) home late.
Ввод: [__________]
```

### Режим 2: Перевод рассказа

1. AI смотрит известные слова пользователя → генерирует английский рассказ
2. Пользователь выбирает длину (диапазоны: 10–20, 20–50, 50–100+ слов)
3. В рассказ подмешиваются незнакомые слова — они **визуально выделены**
4. Нажатие на любое слово → перевод через Yandex Dictionary
5. Рассказ разбит на предложения, показываются по одному:
   - Показываем английское предложение
   - Пользователь вводит русский перевод
   - AI проверяет → фидбек → следующее предложение
6. По мере перевода строится итоговый вид: EN сверху, перевод пользователя снизу
7. После завершения — **4 режима просмотра финала:**
   - Только английский оригинал
   - Только перевод пользователя
   - EN + перевод пользователя (как при вводе)
   - EN + ожидаемый перевод от AI
8. Сводка всех замечаний AI по рассказу в одном месте

## Работа со словами — Yandex Dictionary

Документация: https://yandex.ru/dev/dictionary

Используется в двух местах:
1. **Нажатие на слово в практике** — попап с переводом + кнопка "Добавить в Words8r"
2. **Долгое нажатие на незнакомое слово** — запрос к API, пользователь выбирает нужные варианты перевода, отправляет в Words8r с транскрипцией

При добавлении слова в Words8r: пользователь видит все варианты перевода от API, выбирает нужные, слово сохраняется с выбранными переводами и транскрипцией.

## Синхронизация с Words8r

Words8r добавляет ContentProvider — несколько файлов + запись в `AndroidManifest.xml`, не ломает архитектуру.

Grammar8r обращается по URI:
```
content://dev.sethan8r.sethanwords.provider/words
content://dev.sethan8r.sethanwords.provider/words?level=A1
```

**Чтение (Grammar8r ← Words8r):**
- Автоматически при открытии приложения
- По кнопке в меню — ручная синхронизация

**Запись (Grammar8r → Words8r):**
- Кнопка "Добавить в словарь" из любого упражнения
- Слово отправляется с переводами и транскрипцией (из Yandex Dictionary)
- Категория слов в Words8r: название определить позже (кроме "Grammar Basics")

## Монетизация

**Freemium модель:**
- Теория и расстановка слов — бесплатно навсегда
- AI (генерация + проверка упражнений) — 3 запроса/день бесплатно
- Подписка — безлимитный AI, ~99₽/месяц

**Оплата:** [YooKassa](https://yookassa.ru/developers?lang=ru)

**Специальный доступ:** ручная выдача подписки на любой срок или навсегда — через консоль сервера без изменений в коде. Для тестов, знакомых, акций.

---

## Сервер (подписки)

**Стек:** Kotlin + Ktor, Docker (~50–80 MB образ)
**Хостинг:** VPS ~200₽/месяц (Timeweb / Beget / REG.RU)

```
VPS 200₽/мес
└── Docker
    ├── Ktor (webhook + /subscription endpoint)
    └── SQLite / PostgreSQL (uid → { active, expires })
```

Эндпоинты:
- `GET /subscription?uid=X` → `{ active: true/false, expires: "2026-05-01" }`
- `POST /webhook/yookassa` ← webhook от YooKassa об оплате

## Авторизация — Яндекс OAuth

Причины выбора:
- РФ-аудитория — Яндекс есть у всех
- Уже используем Yandex.GPT и Yandex.Dictionary — один OAuth на всё
- Есть SDK для Android

Поток:
```
Пользователь → Яндекс OAuth → получаем uid
    ↓
Приложение → GET /subscription?uid=X → сервер
    ↓
Сервер → { active: true/false, expires: "..." }
```

## API и расходы

| Сервис | Цена | Использование |
|--------|------|---------------|
| Yandex.GPT Lite | 0,2₽ / 1000 токенов | Генерация упражнений + проверка ответов |
| Yandex.Dictionary | Бесплатно (1000 запросов/день) | Перевод слов, добавление в Words8r — [документация](https://yandex.ru/dev/dictionary) |
| VPS | ~200₽/мес | Сервер подписок |

**Стратегия снижения расходов на GPT:**
- Генерация + проверка = 1 запрос (совмещённый промт)
- Бесплатная практика (расстановка слов) не использует AI вообще
