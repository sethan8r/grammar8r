# Grammar8r — План проекта

## Общая идея

Два связанных Android-приложения:
- **Words8r** — уже существует, приложение для изучения слов
- **Grammar8r** — новое приложение для тренировки грамматики на основе слов из Words8r

Пользователь изучает слова в Words8r, а Grammar8r генерирует упражнения на основе этих слов через Yandex.GPT Lite.

---

## Поток данных

### Сценарий 1: Grammar8r читает слова из Words8r
```
Words8r (Room БД)
    ↓ ContentProvider
Grammar8r (загружает известные слова пользователя)
    ↓
Yandex.GPT Lite (генерирует упражнения ТОЛЬКО с этими словами)
```

### Сценарий 2: Grammar8r отправляет новые слова в Words8r
```
Grammar8r (пользователь встретил новое слово в упражнении → "Добавить в словарь")
    ↓ ContentProvider / Intent
Words8r (добавляет слово → запрашивает Yandex.Dictionary API)
    ↓
Words8r (сохраняет с транскрипцией, переводом, примерами)
```

## Структура проекта (новый репозиторий)

```
Grammar8r/
├── app/          ← Grammar8r (Android-приложение)
├── server/       ← Ktor backend (сервер подписок)
```

**Words8r** остаётся отдельным проектом в Android Studio — не трогаем.

Связь между приложениями только в **рантайме** через ContentProvider. Никакой build-time зависимости между проектами нет.

## Базы данных

Раздельные БД для каждого приложения:

**Words8r БД** (`words8r.db`) — как сейчас:
- Слова, переводы, транскрипции
- Прогресс изучения

**Grammar8r БД** (`grammar8r.db`):
- Копия известных слов (подтянутых из Words8r)
- История упражнений и предложений
- Прогресс по временам глаголов
- Ошибки и слабые места пользователя
- Теория (будет разработана позже)

## Синхронизация между приложениями

Words8r добавляет **ContentProvider** — это несколько файлов + запись в `AndroidManifest.xml`, не ломает текущую архитектуру.

Grammar8r обращается по URI:
```
content://dev.sethan8r.sethanwords.provider/words
content://dev.sethan8r.sethanwords.provider/words?level=A1
```

Синхронизация слов:
- **Автоматически** при открытии Grammar8r — подтягивает новые слова из Words8r
- **По кнопке** — пользователь сам инициирует синхронизацию

## Функциональность Grammar8r

1. Загрузка известных слов из Words8r
2. Генерация упражнений через Yandex.GPT Lite (только с известными словами)
3. Пользователь переводит русское предложение на английский
4. Проверка ответа через Yandex.GPT Lite
5. Генерация + проверка = **1 запрос** (считается как одна операция для лимитов)
6. Отправка новых слов в Words8r
7. Отслеживание прогресса по временам глаголов
8. Теория (бесплатно, будет разработана позже)

## Монетизация

**Freemium модель:**
- Теория — бесплатно навсегда
- ИИ (генерация + проверка упражнений) — 3 запроса/день бесплатно
- Подписка — безлимитный доступ к ИИ, ~99₽/месяц

**Оплата:** [YooKassa](https://yookassa.ru/developers?lang=ru)

**Специальный доступ:** возможность вручную выдавать подписку на любой срок или навсегда (для тестов, знакомых, акций) — через консоль сервера без изменений в коде.

## Сервер (авторизация и подписки)

**Стек:** Kotlin + Ktor (лёгкий, знакомый синтаксис, Docker образ ~50-80MB)

**Хостинг:** VPS ~200₽/месяц (Timeweb / Beget / REG.RU), минимальный тариф

**Что делает сервер:**
- Принимает webhook'и от YooKassa об оплате
- Хранит статусы подписок (uid → { active, expires })
- Отвечает на запрос приложения: `GET /subscription?uid=X` → `{ active: true, expires: "2026-05-01" }`

```
VPS 200₽/мес
└── Docker
    ├── Ktor (webhook + /subscription endpoint)
    └── SQLite / PostgreSQL (кто оплатил и до когда)
```

## Авторизация

**Выбор: Яндекс OAuth**

Причины:
- РФ-аудитория — у всех есть Яндекс
- Уже используем Yandex.GPT и Yandex.Dictionary — один OAuth на всё
- Есть SDK для Android
- Telegram Login возможен, но костыльнее на мобиле (deep links)

**Поток:**
```
Пользователь → Яндекс OAuth → получаем uid
    ↓
Приложение → GET /subscription?uid=X → сервер
    ↓
Сервер → { active: true/false, expires: "..." }
```

## API и расходы

| Сервис | Цена | Использование |
|--------|------|---------------|
| Yandex.GPT Lite | 0,2₽ / 1000 токенов | Генерация + проверка упражнений |
| Yandex.Dictionary | Бесплатно (1000 запросов/день) | Перевод слов, добавление в Words8r — [документация](https://yandex.ru/dev/dictionary) |
| Tatoeba API | Бесплатно | Примеры предложений (опционально) |
| VPS | ~200₽/мес | Сервер подписок |

**Стратегия кэширования:** упражнения генерируются заранее и переиспользуются — снижает расходы на GPT.
