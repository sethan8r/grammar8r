## Фаза 1 — Теория

Самая независимая фича, нет внешних зависимостей.

- [ ] Подключить Room + Hilt в `grammar-app`
- [ ] Спроектировать схему БД: `GrammarTopic` → `GrammarSection` → контент
- [ ] Написать контент теории (тексты, примеры) — засеять из assets JSON
  - Включает тему "Формы глаголов (V1/V2/V3)" — вводная между "Основами" и временами
- [ ] UI: список тем → экран темы с разделами

**Вопросы перед стартом:**
- Какой охват контента? (только времена / шире: артикли, предлоги, модальные глаголы)
- Структура темы: Образование / Употребление / Исключения + примеры?
- Кто пишет тексты теории?
- Связь теории с практикой: кнопка "Потренироваться" из темы?

Параллельно с Фазой 1 или сразу после. Нужна для Фазы 3 (AI-практика зависит от слов).

> Детальный план: [phase2/phase2a_words_read.md](phase2/phase2a_words_read.md)

- [ ] Автосинхронизация при старте + ручная кнопка в меню
- [ ] DictionaryCache (Room) — кэш переводов
- [ ] Перевод по тапу: LingvoLive (primary) + Yandex Dictionary (fallback) + попап UI
- [ ] Кнопка "В мои слова" в попапе — **заглушка** (реальная отправка в Фазе 2б)
- [ ] Words8r sync BottomSheet после микротемы — **заглушка**
- [ ] Проверка минимума слов (50) перед стартом AI-практики
