## Фаза 2 — Words8r внутри Grammar8r

После Фазы 1. Words8r переписывается с нуля внутри Grammar8r — одно приложение, одна БД. `words8r_plan.md` используется только как reference по функциональности.

- [ ] Спроектировать схему БД для словарной базы (слова, isView, isHiding, qRep, прогресс повторений)
- [ ] Seed-данные: базовые глаголы, ~200 неправильных глаголов V1/V2/V3 (таблица `irregular_verbs` в content.db уже есть)
- [x] DictionaryCache (Room) — таблица кэша переводов в user.db
- [ ] Перевод по долгому нажатию: LingvoLive (primary) + Yandex Dictionary (fallback) + попап UI (`CLAUDE.md` → «Перевод слов по долгому нажатию»)
- [ ] Кнопка "В мои слова" в попапе → isView = true, категория "Мои слова"
- [ ] BottomSheet открытия слов после микротемы (isView / isHiding)
- [ ] Вкладка "Слова" — две кнопки "Учить":
  - **"Учить свои слова"** — слова добавленные пользователем (isView = true, не из курса)
  - **"Учить слова курса"** — слова из тем Grammar8r (isView = true, из курса)
- [ ] Вкладка "Словарь" — категории + фильтр по isView
