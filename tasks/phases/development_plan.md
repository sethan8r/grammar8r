Самая независимая фича, нет внешних зависимостей.

- [ ] Подключить Room + Hilt в `grammar-app-android`
- [ ] Серверные заглушки: интерфейсы `AuthRepository` / `EntitlementsProvider` / `AiExerciseRepository` + фейковые реализации через Hilt; их DTO — сразу в модуль `grammar-shared` (контракт клиент↔сервер, см. kickoff_context.md §3.1 и CLAUDE.md)

## Фаза 2 — Words8r внутри Grammar8r

После Фазы 1. Words8r переписывается с нуля внутри Grammar8r — одно приложение, одна БД. `words8r_plan.md` используется только как reference по функциональности.

- [ ] Спроектировать схему БД для словарной базы (слова, isView, isHiding, qRep, прогресс повторений)
- [ ] Seed-данные: базовые глаголы, ~200 неправильных глаголов V1/V2/V3
- [ ] DictionaryCache (Room) — кэш переводов по тапу
- [ ] Перевод по тапу: LingvoLive (primary) + Yandex Dictionary (fallback) + попап UI
- [ ] Кнопка "В мои слова" в попапе → isView = true, категория "Мои слова"
- [ ] BottomSheet открытия слов после микротемы (isView / isHiding)
- [ ] Вкладка "Слова" — две кнопки "Учить":
  - **"Учить свои слова"** — слова добавленные пользователем (isView = true, не из курса)
  - **"Учить слова курса"** — слова из тем Grammar8r (isView = true, из курса)
- [ ] Вкладка "Словарь" — категории + фильтр по isView
- [ ] Алгоритм интервальных повторений (SRS) — детали из words8r_plan.md
- [ ] Все режимы изучения и повторения слов (из words8r_plan.md как reference)
- [ ] Проверка минимума слов (50) перед стартом AI-практики
