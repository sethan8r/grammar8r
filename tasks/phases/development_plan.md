## Фаза 3 — Практика + AI

Зависит от Фазы 2 (нужны слова).

### Режим 1: упражнения в теории (встроены в микротемы)
- [ ] Интеграция Yandex GPT Lite
- [ ] AI-упражнение: перевести русское предложение на английский
- [ ] Проверка ответа через GPT → фидбек в JSON `{ isCorrect, correctedAnswer, feedback }`
- [ ] Показ фидбека пользователю (только разбор ошибки, без мотивации)
- [ ] Лимит 3 запроса/день (счётчик в локальной БД)

### Режим 2: свободная практика (вкладка "Практика")
- [ ] Выбор тем и/или микротем для тренировки
- [ ] AI генерирует упражнения на основе выбранных тем + слов из Words8r
- [ ] История упражнений и прогресс по временам в БД

### Режим 3: перевод рассказа
- [ ] AI смотрит известные слова пользователя → генерирует рассказ на английском
- [ ] В рассказ подмешиваются незнакомые слова (выделены визуально)
- [ ] Нажатие на слово → перевод через Yandex Dictionary (знакомые и незнакомые)
- [ ] Пользователь выбирает длину рассказа (диапазоны: 10–20, 20–50, 50–100 слов)
- [ ] Рассказ разбит на предложения, показываются по одному
- [ ] Для каждого предложения: показываем английское → пользователь вводит русский перевод → AI проверяет → фидбек → следующее предложение
- [ ] По мере ввода — строится итоговый вид: EN предложение сверху, перевод пользователя снизу
- [ ] После перевода всего рассказа — 4 режима просмотра финала:
  - Только английский оригинал
  - Только перевод пользователя
  - Совмещённый: EN + перевод пользователя
  - Совмещённый: EN + ожидаемый перевод от AI
- [ ] Сводка замечаний AI по всему рассказу (все `feedback` собраны в одном месте)
