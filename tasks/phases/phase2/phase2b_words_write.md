> Завершение интеграции: Grammar8r → Words8r.
> Чтение слов (Фаза 2а) — в [phase2a_words_read.md](phase2a_words_read.md).
> Реализация на стороне Words8r — [words8r_plan.md → W2](../../words8r_plan.md).

---

## Два сценария добавления — разные категории

### Сценарий 1: Тап на любое английское слово

Пользователь тапнул на слово в Grammar8r (теория, упражнение, практика):
1. Запрос к **LingvoLive** (primary) → **Yandex Dictionary** (fallback) — получить переводы + транскрипцию
2. Попап: слово + транскрипция + варианты переводов с галочками
3. Нажал "В мои слова" → выбранные переводы → отправить в Words8r
4. **Категория в Words8r: "Мои слова"** (общая, без привязки к теме)

### Сценарий 2: Words8r sync после микротемы

Пользователь завершил микротему → BottomSheet с предустановленными словами темы:
1. Список слов из `MicrotopicVocabulary` assets (захардкожены переводы + транскрипция)
2. Галочки → выбирает нужные → "Добавить"
3. **Категория в Words8r: название темы** — например "Предлоги места", "Личные местоимения"
4. Words8r создаёт новую категорию если её ещё нет

---

## Что нужно сделать в Words8r

### Приём слов из Grammar8r

Добавить ContentProvider INSERT (или Intent broadcast):
```
Принимает: { word, translation[], transcription, category }
```

### Категории слов

Words8r уже имеет систему категорий. Расширить:

| Категория | Источник | Как создаётся |
|-----------|----------|---------------|
| "Мои слова" | Тап на слово в Grammar8r | Существующая или создаётся при первом добавлении |
| "Grammar Basics" | Слова из предтемы "Основы" | Создаётся при первом Grammar8r-синке |
| "Предлоги места" | После микротемы "Предлоги места" | Создаётся динамически по названию микротемы |
| "Личные местоимения" | После микротемы "Личные местоимения" | Аналогично |
| ... и т.д. | | |

Если категория с таким именем уже есть → добавить слово в неё. Если нет → создать.

Words8r не знает заранее какие категории придут из Grammar8r — создаёт их динамически при получении.

---

## Три источника отправки из Grammar8r

### 1. Попап перевода по тапу (Сценарий 1)
- API: LingvoLive → Yandex fallback → кэш `DictionaryCache`
- Пользователь видит варианты с галочками
- Категория: "Мои слова"

### 2. Words8r sync BottomSheet после микротемы (Сценарий 2)
- Данные: `MicrotopicVocabulary` assets (захардкожены)
- Галочки → выбирает нужные
- Категория: название микротемы (например "Предлоги места")

### 3. Попап в WordArrangement упражнении (Сценарий 1)
- Перевод захардкожен в контенте упражнения
- Категория: "Мои слова"

## Что нужно добавить в Words8r (подробно)

**ContentProvider или Intent — принять слово:**
```kotlin
// Вариант A: ContentProvider INSERT
contentResolver.insert(
    Uri.parse("content://dev.sethan8r.sethanwords.provider/words"),
    ContentValues().apply {
        put("word", word)
        put("translations", translations.joinToString("|"))
        put("transcription", transcription)
        put("category", category)  // "Мои слова" или "Предлоги места" и т.д.
    }
)
```

**Логика на стороне Words8r:**
- Найти или создать категорию по имени
- Добавить слово в категорию
- Если слово уже есть в этой категории → игнорировать (или обновить переводы)
- Если слово есть в другой категории → добавить ещё раз в новую (слово может быть в нескольких категориях)

Подробно — [words8r_plan.md → W2](../../words8r_plan.md). Там нужно дописать логику динамических категорий.

## Обработка ошибок на стороне Grammar8r

- Words8r не установлен → "Установи Words8r чтобы добавлять слова" + ссылка на Play Market
- Слово уже в этой категории → тихо игнорировать, не показывать ошибку
- Ошибка записи → короткий toast, не крашить
