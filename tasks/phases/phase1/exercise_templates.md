# Exercise Templates — Grammar8r

Эталонные форматы для 14 типов хардкодных упражнений.  
При написании нового упражнения — сверяться с этим файлом.

---

## 1. TableFill

**Суть:** таблица с подсказками → пользователь вписывает ответ в каждую ячейку.

**Формат:**
```
Задание: [одна строка — что заполнять]

| [Подсказка или Подлежащее] | Ответ |
|---------------------------|-------|
| hint1                     | answer1 |
| hint2                     | answer2 |
```

**explanation:** полное правило группой (не каждый ответ по отдельности) + самая частая ошибка.

**Типичные ошибки при написании:**
- Объяснять каждый ответ отдельно — не нужно, объясняй правило
- Таблица длиннее 7 строк — разбить на два упражнения

## 2. MultipleChoice · CHOICE

**Суть:** предложение с пропуском → выбрать из 2–4 вариантов.

**Формат:**
```
"Предложение с ___." (контекст по-русски в скобках если нужен)

- Вариант
- **Правильный вариант** ✓
- Вариант
```

**explanation:** почему правильный — чётко. Почему каждый неправильный — коротко.

**Типичные ошибки при написании:**
- Правильный ответ всегда на второй позиции — чередовать
- Дистракторы нереалистичные — должны быть типичными ошибками, не абсурдом

---

## 3. MultipleChoice · FORWARD_CHOICE (RU → EN)

**Суть:** русский контекст/предложение → выбрать правильный английский вариант.

**Эталон:** Ex 84.

**Формат:**
```
[Ситуация если нужен контекст:]
"Русское предложение."

- English option
- **English correct option** ✓
- English option
```

**Правила:**
- Если прямой перевод фразы — просто русское предложение без "Выбери английский перевод:"
- Если важен контекст (расстояние, ситуация, интонация) — добавить описание ситуации перед предложением
- Варианты отличаются только нужным грамматическим элементом

**explanation:** почему этот вариант подходит для данной ситуации + чем отличаются неправильные.

---

## 4. MultipleChoice · REVERSE_CHOICE (EN → RU)

**Суть:** английское предложение → выбрать правильный русский перевод.

**Формат:**
```
Переведи на русский:
"English sentence."

- Русский вариант
- **Правильный русский вариант** ✓
- Русский вариант
```

**explanation:** разобрать ключевые слова EN → RU, указать чем отличаются варианты.

## 5. TrueFalse

**Суть:** 5 предложений → пользователь отмечает каждое верно/неверно. Число верных и неверных гибкое (минимум 2 ✓ и 2 ✗ (не показывать эту подсказку пользвоателю)).

**Формат (стандартный — с переводом):**
```
| # | EN | RU | Верно? |
|---|----|----|--------|
| 1 | English sentence. | Русский перевод. | ✓ |
| 2 | Wrong sentence. | Перевод. | ✗ |
```

**Формат (ситуационный — без RU, когда смысл даётся ситуацией):**
```
| # | Ситуация | EN | Верно? |
|---|----------|----|--------|
| 1 | Описание ситуации. | English sentence. | ✓ |
```

**Правила:**
- Всегда ровно 5 предложений
- Неверные предложения — конкретная грамматическая ошибка, не просто "другой смысл"

**explanation:** указать только неверные строки и объяснить ошибку в каждой. Верные не пересказывать.

## 6. WordArrangement

**Суть:** перемешанные слова → собрать правильное предложение. Есть дистракторы.

**Формат:**
```
[RU: перевод.] ИЛИ [Ситуация: описание контекста.]

Правильное предложение: **English sentence.**

| Слово | Перевод | Лишнее? |
|-------|---------|---------|
| Word  | перевод | —       |
| KnownWord | —  | —       |
| Distractor | перевод | ✗ дистрактор |
```

**Правила:**
- `RU:` — когда задание это перевод. `Ситуация:` — когда нужен контекст.
- Перевод "—" для слов уже пройденных в предыдущих карточках (пользователь нажмёт на слово если забыл)
- Минимум 2 дистрактора
- Дистракторы — реалистичные ошибки: другая форма глагола, неверное местоимение, неправильный предлог

**explanation:** объяснять только ошибочные части, не всё предложение. Дистракторы — почему каждый не подходит.

## 7. TextInput

**Суть:** предложения с пропусками → вписать правильный ответ вручную (case-insensitive).

**Формат (стандартный — несколько пунктов):**
```
1. "___ is the capital of France?" (Спрашиваю о городе)
   Ответ: **What**

2. "___ are you late?" (Хочу узнать причину)
   Ответ: **Why**

3. "___ does she live?" (Спрашиваю о месте)
   Ответ: **Where**
```

**Правила:**
- Минимум 2 пункта, обычно 3
- Контекст в скобках — подсказка на русском, но не перевод самого пропуска
- Если несколько правильных вариантов: `Ответ: **isn't** / **is not**`

**explanation:** общее правило для серии + типичные ошибки (регистр, апостроф и т.д.).

## 8. DialogRestore

**Суть:** диалог с пропуском → выбрать правильную реплику.

**Формат:**
```
A: "Реплика или вопрос?"
B: ___

- Wrong option
- **Correct option** ✓
- Wrong option
```

**Правила:**
- Всегда 3 варианта, все на английском
- Неправильные — грамматически неверные формы (isn't/aren't/am not и т.д.), а не просто другой смысл
- Использовать только после изучения вопросов и отрицаний

**explanation:** почему именно эта грамматическая форма правильная, а не просто "так говорят".

## 9. ErrorCorrection

**Суть:** сломанное английское предложение → выбрать правильный вариант.

**Формат:**
```
В предложении есть ошибка. Выбери правильный вариант:

"Wrong English sentence."

- Wrong variant
- **Correct variant** ✓
- Wrong variant
```

**Правила:**
- В условии — только сломанное английское предложение, без русского перевода
- Если нужен русский контекст → использовать FORWARD_CHOICE вместо ErrorCorrection
- Только правильный вариант помечается ✓
- Неправильные варианты — другие частые ошибки на то же правило

**explanation:** назвать конкретную ошибку в исходном предложении + объяснить правило.

## 10. ConstructionMeaning

**Суть:** грамматическая конструкция целиком → выбрать правильный русский смысл из 4.

**Формат:**
```
Выбери правильный перевод:

"English grammar construction."

- **Правильный перевод** ✓
- Неправильный перевод
- Неправильный перевод
- Неправильный перевод
```

**Правила:**
- Всегда 4 варианта
- Неправильные — правдоподобные ошибки (перепутать hers/his, not/isn't и т.д.)

**explanation:** разобрать конструкцию пословно. Указать что именно перепутали неправильные варианты.

## 11. Matching

**Суть:** 4–6 пар → соединить линиями.

**Формат:**
```
Задание: соедини [что] с [чем].

| Левая колонка | Правая колонка |
|---------------|----------------|
| item1         | match1         |
| item2         | match2         |
| item3         | match3         |
| item4         | match4         |
```

**Правила:**
- 4–6 пар. 4 — стандарт; до 6 когда нужно покрыть весь логический список (например все вопросительные слова)
- Без ✓ маркеров — пользователь соединяет интерактивно
- Названия колонок — произвольные под контент, пользователь их не видит

**explanation:** краткое правило по каждой паре.

## 12. Categorization

**Суть:** слова/ситуации → перетащить в правильные колонки-категории.

**Формат:**
```
Задание: перетащи [что] в нужную колонку.

| Категория 1 | Категория 2 |
|-------------|-------------|
| item1       | item2       |
| item3       | item4       |
```

**Правила:**
- 2–3 категории
- 3–5 элементов в каждой (итого 6–15 элементов)
- Использовать только там где это логично: предлоги in/on/at, маркеры времени, типы слов

**explanation:** правило для каждой категории одной строкой.

## 13. Transformation

**Суть:** дано предложение → трансформировать по правилу.

**Формат:**
```
Задание: [описание трансформации — одна строка]

1. "Original sentence." → **"Transformed sentence."**
2. "Original sentence." → **"Transformed sentence."**
3. "Original sentence." → **"Transformed sentence."**
```

**Правила:**
- Всегда 3 пункта
- Одна трансформация на всё упражнение — одно правило, три разных примера
- Тип трансформации может быть любым: this→these, "of X"→"X's", утверждение→вопрос и т.д.

**explanation:** назвать правило трансформации + что чаще всего упускают (артикль, порядок слов, форму глагола).

## 14. FindTheOdd

**Суть:** 4 слова/конструкции — найти лишнее.

**Формат:**
```
[Что объединяет три из четырёх — одним предложением]:

- item1
- item2
- item3
- **item4 (лишнее)** ✓
```

**Правила:**
- Всегда 4 элемента, один правильный ответ
- Объяснение ЧТО объединяет три — обязательно в условии задания
- Использовать только там где "лишнее" логически очевидно по правилу, не по ощущению

**explanation:** назвать принцип объединения трёх + почему четвёртое не подходит.

## 15. AI Exercise

**Суть:** задание генерируется AI в реальном времени по шаблону промта. Пользователь отвечает в свободное поле или заполняет пропуски прямо в тексте.

**Формат:**
```
**Title:** "Короткое название задания"
**Input Mode:** FREE_WRITE / FILL_BLANKS
**Words Source:** NONE / GENERAL / INFORMAL_ENGLISH / VERB_FORMS
**AI Config Profile:** EXERCISE_LIGHT / EVALUATION_ONLY / EXERCISE_HEAVY_50..500
**User Instruction:** "Одна строка — что делать пользователю. Показывается до нажатия [Начать задание]."
**Prompt Template:** "Полная инструкция для AI. Что генерировать, как проверять ответ, как объяснять ошибку. Последняя строка: Пример вывода AI: 'конкретный текст который AI выдаст пользователю'."
```

**Правила по полям:**

| Поле | Правило |
|------|---------|
| Title | Глагол + объект: "Вставь предлог", "Переведи предложение", "Сделай отрицание" |
| Input Mode | FILL_BLANKS — если AI присылает текст с пропусками `[___]`. FREE_WRITE — всё остальное |
| Words Source | NONE для большинства упражнений предтемы. GENERAL когда нужны слова из словаря пользователя |
| AI Config Profile | EXERCISE_LIGHT — стандарт. EXERCISE_HEAVY если ответ AI > 100 токенов |
| User Instruction | Без технических деталей — только что делать. Не упоминать AI, не объяснять механику |
| Prompt Template | Обязательно заканчивается строкой `Пример вывода AI: '...'` с конкретным текстом |

**Правила Prompt Template:**
- Написать ЧТО генерировать (тип задания, язык, длину)
- Написать КАК проверять (что считать правильным, принимать ли сокращения)
- Написать КАК объяснять ошибку (по-русски, конкретно, без воды)
- `Пример вывода AI:` — обязателен. Без него нельзя проверить корректность задания

**Типичные ошибки при написании:**
- Нет `Пример вывода AI:` — нельзя проверить что AI выдаст
- User Instruction слишком техническая ("AI даст FILL_BLANKS...") — пользователь это не должен видеть
- Prompt Template не указывает язык объяснения ошибки — AI может ответить по-английски
