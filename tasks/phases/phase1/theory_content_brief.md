# Бриф: контент теории для Grammar8r

## Контекст

Grammar8r — Android-приложение для изучения английской грамматики.
Теория разбита на **темы** (например, "Present Simple"), каждая тема состоит из **микротем** (например, "Образование", "Употребление").

Весь контент будет загружен в базу данных приложения из JSON-файла.

---

## Стиль изложения

- Объясняй **просто и дружелюбно** — как будто рассказываешь ребёнку или человеку, который впервые слышит о грамматике
- Никакой сухой академической терминологии без объяснения
- Каждое правило сразу подкреплено примером прямо в тексте теории
- Короткие абзацы, простые слова

---

## Структура вывода

Выводи контент в формате JSON. Один файл = весь контент.

```json
{
  "topics": [
    {
      "id": 1,
      "title": "Основы",
      "level": "A0",
      "order": 1,
      "isPretopic": true,
      "microtopics": [...]
    },
    {
      "id": 2,
      "title": "Present Simple",
      "level": "A0",
      "order": 2,
      "isPretopic": false,
      "microtopics": [...]
    }
  ],
  "pretopicVocabulary": [...]
}
```

### Структура микротемы

```json
{
  "id": 1,
  "topicId": 1,
  "title": "Артикли: a и an",
  "order": 1,
  "theory": "Текст теории — дружелюбный, простой, с примерами прямо внутри текста...",
  "theorySummary": "Краткая суть в 2–3 предложениях — для подсказки во время практики.",
  "examples": [
    { "id": 1, "russian": "Это кошка.", "english": "This is a cat." },
    { "id": 2, "russian": "Он ест яблоко.", "english": "He is eating an apple." }
  ],
  "exercises": [
    {
      "id": 1,
      "correctSentence": "She has a dog.",
      "words": [
        { "word": "She", "translation": "Она" },
        { "word": "has", "translation": "имеет / у неё есть" },
        { "word": "a", "translation": "артикль (один/какой-то)" },
        { "word": "dog", "translation": "собака" }
      ]
    }
  ]
}
```

**Требования к каждой микротеме:**
- `theory` — минимум 3–5 абзацев, объяснение правила + примеры прямо в тексте. Без списков-буллетов, живой текст.
- `theorySummary` — 2–3 предложения, суть правила. Показывается как подсказка во время практики по кнопке "?".
- `examples` — минимум 5 пар RU → EN, разнообразные, жизненные ситуации
- `exercises` — минимум 3 упражнения на расстановку слов. Предложения простые (5–8 слов). Для каждого слова обязательно поле `translation`.

## Что нужно сгенерировать

### 1. Предтема: "Основы" (isPretopic: true)

Микротемы:
1. **Артикли: a и an** — когда использовать неопределённый артикль
2. **Артикль: the** — когда использовать определённый артикль
3. **Без артикля** — когда артикль не нужен совсем
4. **Базовые предлоги места** — in, on, at, near, under, between
5. **Базовые предлоги времени** — in, on, at (для времени)
6. **Базовые предлоги направления** — to, from, into, out of
7. **Личные местоимения** — I, you, he, she, it, we, they + когда какое использовать
8. **Притяжательные местоимения** — my, your, his, her, its, our, their

### 2. Present Simple

Микротемы:
1. **Что такое Present Simple** — зачем нужно, общая идея
2. **Образование: утверждение** — I/you/we/they + глагол, he/she/it + глагол+s
3. **Образование: отрицание** — don't / doesn't
4. **Образование: вопрос** — Do / Does
5. **Употребление** — привычки, факты, расписания
6. **Маркеры времени** — always, usually, often, sometimes, never, every day/week

### 3. Present Continuous

Микротемы:
1. **Что такое Present Continuous** — общая идея, отличие от Present Simple
2. **Образование** — am/is/are + глагол-ing
3. **Употребление** — что происходит прямо сейчас, временные ситуации
4. **Маркеры времени** — now, right now, at the moment, today, this week
5. **Глаголы, которые не используются в Continuous** — know, like, love, hate, want, need

### 4. Past Simple

Микротемы:
1. **Что такое Past Simple** — общая идея
2. **Образование: правильные глаголы** — глагол + ed
3. **Образование: неправильные глаголы** — объяснение + топ-20 самых частых
4. **Образование: отрицание и вопрос** — didn't, Did...?
5. **Употребление** — завершённые действия в прошлом
6. **Маркеры времени** — yesterday, last week/year, ago, in 2020

### 5. Past Continuous

Микротемы:
1. **Что такое Past Continuous** — общая идея
2. **Образование** — was/were + глагол-ing
3. **Употребление** — действие в процессе в прошлом, фон для другого действия
4. **Past Simple vs Past Continuous** — разница на примерах

### 6. Present Perfect

Микротемы:
1. **Что такое Present Perfect** — общая идея, почему это сложно для русских
2. **Образование** — have/has + причастие прошедшего времени (Past Participle)
3. **Правильные и неправильные глаголы в PP**
4. **Употребление** — опыт, результат, недавнее прошлое
5. **Маркеры времени** — ever, never, already, yet, just, recently

### 7. Present Perfect Continuous

Микротемы:
1. **Что такое Present Perfect Continuous**
2. **Образование** — have/has been + глагол-ing
3. **Употребление** — длительное действие от прошлого до настоящего
4. **Present Perfect vs Present Perfect Continuous** — разница

### 8. Past Perfect

Микротемы:
1. **Что такое Past Perfect**
2. **Образование** — had + Past Participle
3. **Употребление** — действие до другого действия в прошлом
4. **Маркеры времени** — before, after, already, when, by the time

### 9. Future Simple (will)

Микротемы:
1. **Что такое Future Simple**
2. **Образование** — will + глагол
3. **Употребление** — спонтанные решения, предсказания, обещания
4. **Отрицание и вопрос** — won't, Will...?
5. **Маркеры времени** — tomorrow, next week, soon, in the future

### 10. Future с "going to"

Микротемы:
1. **Going to vs Will** — когда какое использовать
2. **Образование** — am/is/are going to + глагол
3. **Употребление** — планы, намерения, очевидные предсказания

### 11. Future Continuous

Микротемы:
1. **Что такое Future Continuous**
2. **Образование** — will be + глагол-ing
3. **Употребление** — действие в процессе в будущий момент

### 12. Future Perfect

Микротемы:
1. **Что такое Future Perfect**
2. **Образование** — will have + Past Participle
3. **Употребление** — действие завершится до определённого момента в будущем
4. **Маркеры времени** — by tomorrow, by next year, by the time

## Базовый словарь предтемы (pretopicVocabulary)

Это список слов, который будет предложен пользователю для добавления в приложение по изучению слов после прохождения предтемы.

Сгенерируй список ~60–80 слов: все артикли, все предлоги из предтемы, личные и притяжательные местоимения, базовые глаголы-связки (be, have, do), базовые вспомогательные глаголы.

Формат:
```json
{
  "word": "in",
  "translation": "в, внутри",
  "transcription": "[ɪn]"
}
```

---

## Важные правила

1. **Не сокращай.** Каждая микротема должна быть полноценной — с нормальным объяснением, не в одну строчку.
2. **Примеры разнообразные.** Не повторяй одни и те же слова в примерах. Используй разные жизненные ситуации: еда, работа, школа, путешествия, семья, хобби.
3. **Упражнения на расстановку слов** — предложения должны точно демонстрировать правило текущей микротемы. Не слишком сложные, 5–8 слов.
4. **Переводы слов в упражнениях** — для каждого слова в массиве `words` обязательно поле `translation`. Перевод короткий, понятный.
5. **IDs сквозные** — id микротем, примеров, упражнений — уникальные числа по всему файлу, не повторяются.
