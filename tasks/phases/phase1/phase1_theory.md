# Фаза 1 — Теория

## Структура контента

```
Теория
├── Предтема: "Основы"  ← особая категория, идёт первой
│   ├── Микротема: Артикли (a / an / the / -)
│   ├── Микротема: Предлоги (in, on, at, to, ...)
│   ├── Микротема: ... (другие базовые вещи)
│   └── По окончании → предложение отправить базовый словарь в Words8r (категория "Grammar Basics")
│
├── Present Simple
│   ├── Микротема: Образование
│   ├── Микротема: Употребление
│   ├── Микротема: Маркеры времени
│   └── ...
│
├── Present Continuous
├── Past Simple
├── ...и остальные времена
```

---

## Структура одной микротемы — пошаговые карточки

Микротема — это **последовательность шагов** (карточек), а не один длинный экран.
Пользователь листает вперёд кнопкой "Далее". Прогресс-точки или бар сверху.

```
Шаг 1: Теория        ← короткий текст, одно правило, без скролла
Шаг 2: Пример        ← одна пара RU → EN с пояснением
Шаг 3: Пример        ← ещё одна пара (если тема требует)
Шаг 4: Практика      ← расставить слова (всегда доступно)
Шаг 5: Практика      ← ещё одно упражнение, чуть сложнее
Шаг 6: AI-практика   ← только при подписке / лимит 3/день
```

На карточках практики — иконка `?` в углу.
Нажал → снизу выезжает BottomSheet с `theorySummary` (2–3 предложения, суть правила).

Слова для AI-упражнений берутся из Words8r (известные слова пользователя).

## Прогресс

- На экране **внутри темы** — прогресс-бар вверху, разбитый на сегменты (каждый сегмент = одна микротема)
  - Пройденные сегменты закрашены, непройденные — нет
  - Нажатие на сегмент → пузырёк (bubble/tooltip, как в комиксах) с названием микротемы
    и кнопкой "Перейти" — для быстрого возврата к нужной теории
- На экране **списка тем** — у каждой темы визуально видно прогресс (сколько сегментов закрашено),
  без цифр
- Если пользователь вышел из темы не завершив её — на экране списка тем у этой темы появляется
  кнопка **"Продолжить"** (аналогично кнопке продолжения сессии повторения в Words8r)
- Микротема считается пройденной после выполнения практики

## Дерево тем (быстрая навигация)

Внизу вкладки **Теория** — кнопка "Все темы" (или иконка оглавления).
По нажатию снизу выезжает **BottomSheet** с деревом:

```
Основы
  ├── Артикли
  ├── Предлоги
  └── Местоимения
Формы глаголов (V1/V2/V3)
  ├── Правильные глаголы
  └── Неправильные глаголы
Present Simple
  ├── Образование
  ├── Употребление
  └── Маркеры времени
...
```

- У каждой темы — короткое описание (1 строка), чтобы сразу понятно о чём
- Нажатие на микротему → переход напрямую туда
- Удобно для возврата к теории когда что-то забыл

## Работа со словами в практике

### Нажатие на слово (короткое)
- Маленький попап прямо у слова
- Показывает перевод слова (из JSON контента, захардкожен)
- Кнопка "Добавить в Words8r" → отправляет слово в Words8r (категория — придумать название)

### Долгое нажатие на слово (для незнакомых слов вне базового словаря)
1. Вызов Yandex Dictionary API → возвращает варианты переводов + транскрипцию
2. Всплывающее окно: показываем варианты переводов, пользователь выбирает нужные
3. Кнопка "Добавить в Words8r" → слово с выбранными переводами и транскрипцией отправляется в Words8r
4. Категория в Words8r: название придумать позже

Документация Yandex Dictionary: https://yandex.ru/dev/dictionary

## Предтема "Основы" — базовый словарь

Список слов захардкожен в assets (артикли, предлоги, базовые слова).
Каждое слово содержит: `word`, `translation`, `transcription`.

После прохождения всех микротем предтемы:
→ Показываем экран/диалог: "Хочешь добавить базовые слова в Words8r?"
→ Список слов с переводами, галочки — пользователь выбирает какие добавить
→ Отправляем выбранные слова в Words8r с переводами и транскрипцией
→ Категория: "Grammar Basics"

## Вкладка "Практика" (отдельный таб)

- Пользователь выбирает темы и/или конкретные микротемы
- AI генерирует упражнения на основе выбранных тем + слов из Words8r
- Удобно для тех, кто уже знает теорию и хочет практиковаться без навигации по теории
- Гибкие настройки (детали определить позже)
- Лимит: подписка / 3 запроса в день бесплатно

## БД — схема

### GrammarTopic
| Поле | Тип | Описание |
|------|-----|----------|
| id | Int PK | |
| title | String | "Present Simple" |
| description | String | Короткое описание темы (для дерева тем) |
| order | Int | Порядок в списке |
| isPretopic | Boolean | true только для "Основы" |

### GrammarMicrotopic
| Поле | Тип | Описание |
|------|-----|----------|
| id | Int PK | |
| topicId | Int FK | Ссылка на тему |
| title | String | "Образование" |
| order | Int | Порядок внутри темы |
| theoryContent | String | Полный текст теории |
| theorySummary | String | Краткая суть (2–3 предл.) — для подсказки "?" в практике |

### GrammarExample
| Поле | Тип | Описание |
|------|-----|----------|
| id | Int PK | |
| microtopicId | Int FK | |
| russian | String | Русское предложение |
| english | String | Английский перевод |
| order | Int | |

### WordArrangementExercise
| Поле | Тип | Описание |
|------|-----|----------|
| id | Int PK | |
| microtopicId | Int FK | |
| correctSentence | String | Правильное предложение |
| words | String | JSON-массив объектов: `[{"word":"I","translation":"Я"}, ...]` |

### PretopicVocabulary (захардкожено в assets, не в Room)
```json
[
  { "word": "a", "translation": "неопределённый артикль (один, какой-то)", "transcription": "[ə]" },
  { "word": "the", "translation": "определённый артикль (этот, тот)", "transcription": "[ðə]" },
  { "word": "in", "translation": "в, внутри", "transcription": "[ɪn]" }
]
```

### UserMicrotopicProgress
| Поле | Тип | Описание |
|------|-----|----------|
| microtopicId | Int PK FK | |
| isCompleted | Boolean | |
| completedAt | Long? | Unix timestamp |
