# Фаза 1 — Теория

## Главный принцип — качество важнее скорости

> Это не просто список фич. Это стандарт, которому должна соответствовать каждая карточка.

Теория в Grammar8r — это объяснение от умного друга, который сидит рядом. Не учебник, не Wikipedia. Каждое правило разжёвано так, что пользователю остаётся только проглотить. Никакой воды, но и никакой спешки — если нюанс важен, он объяснён. Если правило имеет исключения, они показаны. Если можно запутаться — заранее предупреждаем где.

**Карточка считается готовой только если:**
- Теорию поймёт человек, который видит правило впервые в жизни
- Примеры живые — из еды, работы, семьи, путешествий, а не "The cat is on the mat"
- Упражнения проверяют именно это правило, а не что-то соседнее
- AI-упражнение даёт фидбек конкретно: "Ошибка в окончании глагола — для he/she/it нужен -s", а не "неправильно"

**Растянутость = глубина, не вода.** Лучше 5 коротких карточек с одним нюансом каждая, чем одна длинная где всё навалено в кучу.

Именно это — причина, по которой люди платят подписку. Не потому что "приложение красивое", а потому что они реально начали понимать английский.

## Структура: микротема → карточки → экран упражнений

Микротема разбита на **карточки** — каждая карточка = одно маленькое правило или нюанс.
Пользователь листает карточки вверх/вниз. Прогресс-бар сверху показывает позицию внутри микротемы.

### Структура карточки

```
[ Теория: 1–3 абзаца, одно правило ]
[ Примеры: 2–4 пары RU → EN        ]
[ Кнопка: "К упражнениям →"         ]
```

Карточка содержит **только теорию и примеры**. Упражнения — на отдельном экране.

### Экран упражнений

Открывается по кнопке "К упражнениям" с карточки. Единый экран для всех упражнений в приложении.

```
┌─────────────────────────────────┐
│  Упражнение 1 из 5           [?]│
│  [краткое название типа задания]│
│                                 │
│  [само задание — весь экран]    │
│                                 │
│         [ Проверить ]           │
└─────────────────────────────────┘
```

- **Прогресс** — "Упражнение X из N" вверху
- **Кнопка `?`** — в правом верхнем углу на каждом упражнении. Нажал → AlertDialog с `theorySummary` (2–3 предложения) + 1 ключевой пример из карточки. Закрывается обратно на упражнение.
- **"Проверить"** → показывает верно/неверно + фидбек → "Далее"
- После всех хардкодных — AI-упражнение (тот же экран, другой источник)
- **Правило для всего приложения:** кнопка `?` с theorySummary есть на всех экранах упражнений, не только в теории

Пример разбивки микротемы "Предлоги места":
```
Карточка 1: in, on, at — основная тройка
  → 5 упражнений (MultipleChoice + ForwardChoice + TextInput)
  → 1 AI-упражнение
Карточка 2: near, beside/by — степени близости
  → 3 упражнения (ForwardChoice + Matching)
  → 1 AI-упражнение
Карточка 3: under, above, behind, in front of
  → 4 упражнения (MultipleChoice + Matching + TrueFalse)
  → 1 AI-упражнение
Карточка 4: Всё вместе — смешанная практика
  → 5 упражнений всех типов
  → 1 AI-упражнение
```

## Типы упражнений

Полный глобальный список с правилами применения — в [grammar8r_plan.md](../../grammar8r_plan.md) → раздел "Типы хардкодных упражнений".

**Особенности для предтемы "Основы":**
- Упор на **ForwardChoice** и **ReverseChoice** — пользователь ориентируется на русский, слов почти не знает
- **Categorization** обязательна для предлогов (in/on/at → распредели слова по колонкам)
- **TableFill** обязательна для `to be` и `have/has`
- **DialogRestore** — только после карточек с вопросами и отрицаниями
- **Transformation** — два задания подряд: сначала сделай отрицание, потом вопрос из того же утверждения
- **ConstructionMeaning** — для `There is/are`, отрицаний, вопросительных конструкций
- Прогрессия сложности: MultipleChoice/ForwardChoice → TextInput на ту же конструкцию

## AI-упражнения (заглушки — промты разрабатываются отдельно)

AI-упражнения идут в конце карточки, после хардкодных. Доступны: Free = 3/день, Tier 1/2 = лимит TBD.

Слова для AI-упражнений в предтеме берутся **только из контента предтемы** (свой список, не Words8r — пользователь ещё не подключил словарь). Для последующих тем — из Words8r.

Возможные типы AI-упражнений (конкретные промты — после написания теории):

| Тип | Описание |
|-----|----------|
| Перевод RU→EN | AI даёт RU предложение на правило карточки, пользователь переводит, AI проверяет |
| Заполни пропуск (AI-генерация) | AI генерирует предложение с пропуском на нужное правило |
| Придумай своё | AI просит пользователя составить предложение по правилу, проверяет |
| Мини-диалог | AI ведёт короткий диалог, намеренно используя структуры текущей карточки |

Фидбек от AI: `{ isCorrect: bool, correctedAnswer: "...", feedback: "..." }` — только разбор ошибки, без мотивации, по-русски, 1–2 предложения.

## Предупреждение "Выучи основы" (одноразовое)

Срабатывает когда пользователь впервые нажимает на любую тему после прохождения предтемы "Основы".

**Логика:**
1. Grammar8r читает через ContentProvider слова из категории "Grammar Basics" в Words8r
2. Считает количество слов с `qRep = 0` (ещё не выучены)
3. Если таких слов > 0 — показывает AlertDialog:

```
"Ты ещё не выучил X слов из предтемы «Основы».
Эти слова — база, без них будет сложнее понимать следующие темы."

[Пойду учить слова (рекомендуется!)]
[Всё равно начать тему]
```

4. **"Пойду учить слова"** → переход в Words8r на экран "Учить для Grammar8r"
5. **"Всё равно начать тему"** → флаг `basics_warning_dismissed = true` сохраняется локально (SharedPreferences). Диалог больше **никогда** не появляется — ни при входе в эту тему, ни в любую другую.

**Важно:**
- Диалог появляется максимум один раз за всё время использования приложения
- Не блокирует — пользователь всегда может пройти дальше
- Если пользователь слил слова из "Основ" но не открывал ни одну тему — диалог покажется при первом открытии любой темы
- Если пользователь не сливал слова из "Основ" вообще (категория "Grammar Basics" пуста) — диалог не показывается

## Прогресс

- На экране **внутри темы** — прогресс-бар вверху, разбитый на сегменты (каждый сегмент = одна микротема)
  - Пройденные сегменты закрашены, непройденные — нет
  - Нажатие на сегмент → пузырёк (bubble/tooltip, как в комиксах) с названием микротемы
    и кнопкой "Перейти" — для быстрого возврата к нужной теории
- На экране **списка тем** — у каждой темы визуально видно прогресс (сколько сегментов закрашено),
  без цифр
- Если пользователь вышел из темы не завершив её — на экране списка тем у этой темы появляется
  кнопка **"Продолжить"** (аналогично кнопке продолжения сессии повторения в Words8r)
- Микротема считается пройденной после выполнения практики

### Цвета состояний микротем (экран списка микротем внутри темы)

| Состояние | Цвет |
|-----------|------|
| Пройдена | Светло-серый |
| Следующая по очереди | Оранжевый (Accent) |
| Остальные | Тёмно-серый |

Прыгать между микротемами можно свободно — оранжевый цвет только подсказка, не блокировка.

### Иконка Download (синк слов в Words8r)

Если микротема пройдена **и** у неё есть словарная база для Words8r — справа от названия появляется иконка `Icons.Default.Download` (стрелка вниз с чертой).

- Нажатие → экран синка: список слов, все предвыбраны галочкой, пользователь снимает лишние → [Добавить] / [Отменить]
- Иконка остаётся доступной всегда — пользователь может слить слова в любой момент
- Защита дублей: Words8r делает INSERT OR IGNORE — если слово уже в этой категории, пропускается молча

## Поиск по теории

Сверху вкладки **Теория** — поисковая строка. Ищет по названиям тем **и** микротем одновременно.

**Поведение при вводе:**
- Темы и микротемы у которых нет совпадений — исчезают (`AnimatedVisibility`)
- Тема чьё **название совпадает** — показывается полностью развёрнутой со всеми микротемами
- Тема в которой **совпадает микротема** — показывается "схлопнутой" с заголовком темы + только совпадающие микротемы внутри (родительская тема видна — пользователь понимает контекст)
- Совпадение без учёта регистра, поддержка русского и английского

**Порядок результатов (релевантность):**
1. Точное совпадение с начала названия
2. Содержит введённую строку в названии темы
3. Содержит введённую строку в названии микротемы

**UX:**
- Пока строка поиска пустая — обычный список тем
- Кнопка "✕" очищает поиск и возвращает полный список
- Нет результатов → "Ничего не найдено" в центре

**Нажатие на результат:**
- Тема → открывает экран темы
- Микротема → напрямую переходит в микротему (минуя экран темы)

## Повторное прохождение микротемы (сброс хардкодных заданий)

Когда пользователь входит в **уже завершённую** микротему (`isCompleted = true`) — на экране списка карточек (до того как он начал листать) показывается `AlertDialog`:

```
"Хочешь перепройти упражнения?
Теория и прогресс сохранятся —
сбросятся только хардкодные задания."

[ Сбросить задания ]   [ Просто посмотреть ]
```

**При нажатии "Сбросить задания":**
- `UserCardHardcodeStats` удаляется для всех карточек микротемы
- `UserCardProgress.isCompleted = false` для всех карточек микротемы
- `UserMicrotopicProgress.isCompleted` остаётся `true` — сегмент в прогресс-баре **не сбрасывается** (пользователь уже прошёл тему, это просто повторение)
- `UserCardAiStats` **не трогаем** — AI-прогресс сохраняется

**При нажатии "Просто посмотреть":**
- Ничего не сбрасывается, пользователь просто читает теорию

**Диалог показывается только один раз за сессию** — если пользователь уже ответил "Просто посмотреть" и вышел-зашёл, диалог не повторяется до следующего запуска приложения.

## Работа со словами в практике

### Нажатие на слово (короткое)
- Маленький попап прямо у слова
- Показывает перевод слова (из JSON контента, захардкожен)
- Кнопка "Добавить в Words8r" → отправляет слово в Words8r (категория — придумать название)

### Долгое нажатие на слово (для незнакомых слов вне базового словаря)
1. Вызов Yandex Dictionary API → возвращает варианты переводов + транскрипцию
2. Всплывающее окно: показываем варианты переводов, пользователь выбирает нужные
3. Кнопка "Добавить в Words8r" → слово с выбранными переводами и транскрипцией отправляется в Words8r
4. Категория в Words8r: название придумать позже

Документация Yandex Dictionary: https://yandex.ru/dev/dictionary

## Words8r sync — после каждой микротемы

Sync предлагается **после завершения каждой микротемы**, у которой есть словарная база.
Не ждём конца всей предтемы — момент горячий, пользователь только что изучил эти слова.

Диалог/BottomSheet: "Хочешь добавить [предлоги места] в Words8r?"
→ Список слов с переводами, галочки
→ Пользователь выбирает какие добавить
→ Категория: "Grammar Basics"

### Словарная база по микротемам (assets JSON)

Формат каждой записи: `{ "word": "on", "translations": ["на", "над"], "transcription": "[ɒn]" }`

| Микротема | Слова для sync |
|-----------|---------------|
| Предлоги места | in, on, at, near, under, between, above, behind, in front of |
| Предлоги времени | in, on, at, before, after, during, since, for, until |
| Предлоги направления | to, from, into, out of, through, past, along, across |
| Предлог of | of |
| Личные местоимения | I, you, he, she, it, we, they |
| Притяжательные местоимения | my, your, his, her, its, our, their |
| Указательные местоимения | this, that, these, those |
| Вопросительные слова | what, where, when, who, why, how, which, whose |
| Глагол to be | am, is, are, was, were |
| There is / There are | there |
| Глагол have/has | have, has |

> Артикли `a`, `an`, `the` — **не добавляются** в Words8r (нет перевода, только теория).

Полный список с переводами и транскрипцией — готовится вместе с контентом теории.

## Логика экрана упражнений и статистики

### Хардкодные упражнения — сессия

```
Начало: isCompleted = false, сессионный счётчик correct/total = 0
  ↓ каждый ответ: correct++ или total++ (только в памяти, не в БД)
  ↓ N/N выполнено:
    → запись UserCardHardcodeStats (или перезапись если была)
    → UserCardProgress.isCompleted = true
    → экран итогов: "Выполнено! X из N правильно"
    → кнопки: [Следующая карточка] / [Умная практика] / [Повторить]
  ↓ "Повторить":
    → сессионные счётчики сброшены, статистика НЕ перезаписывается пока не дойдёт до N/N снова
```

**Если это последняя карточка микротемы:**
кнопка "Следующая карточка" → "Завершить микротему"
После нажатия → BottomSheet с предложением Words8r sync

### AI-упражнения — поштучно

- Каждое выполненное AI-упражнение сразу пишет в `UserCardAiStats`
- Кнопки после фидбека: [Ещё задание] / [К карточке]
- Лимит: Free = 3/день, Tier 1/2 = TBD (проверяется по `UserAiRequestCount`)

**Два формата ответа AI — зависит от типа упражнения:**

*Простые* (вставить одно слово, выбрать форму):
```json
{ "isCorrect": true, "correctedAnswer": "...", "feedback": "..." }
```

*Открытые* (написать предложение, перевести текст):
```json
{
  "score": 85,
  "correctedAnswer": "She doesn't like coffee.",
  "feedback": "Структура верная, но: 'don't' → 'doesn't' для she/he/it.",
  "errors": ["don't → doesn't (3-е лицо ед.ч.)"]
}
```

**Шкала score (0–100):**
- 90–100: идеально или опечатка
- 70–89: структура верная, 1–2 ошибки в формах/окончаниях
- 40–69: понятно, но серьёзные ошибки
- 1–39: частично угадал, структура нарушена
- 0: смысл не ясен, набор слов без структуры

**Важно для промта:** AI засчитывает все грамматически верные варианты ответа, не только один эталонный. "I do not like" = "I don't like" = 100%.

В `UserCardAiStats` для открытых упражнений пишем `score` (0–100), для простых — конвертируем `isCorrect` в 100/0.

### Что видно в разделе Статистика

По каждой теме:
- Хардкод: "X из Y карточек пройдено", процент правильных ответов по всем карточкам
- Умная практика: "Выполнено N заданий", процент правильных (если хватает данных)

Агрегация: тема → микротема → карточка → `UserCardHardcodeStats` + `UserCardAiStats`
