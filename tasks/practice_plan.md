# Grammar8r — План вкладки «Практика»

Подробный план всех режимов раздела «Практика».
Краткая схема — в [grammar8r_plan.md](grammar8r_plan.md) → раздел «Практика».

---

## Общие принципы

- Все режимы Практики — **только AI-генерация**. Никаких захардкоженных упражнений. Разница между тирами — только дневной лимит запросов (Free: 3/день, Tier 1: 30, Tier 2: 50).
- Слова для предложений берутся из Words8r пользователя по алгоритму выборки (см. grammar8r_plan.md → «Алгоритм выборки слов»)
- Фидбек всегда по-русски, конкретный, без мотивации — только разбор ошибки
- Пользователь не может начать режим если не выполнены минимальные условия (нет слов, нет пройденных тем и т.д.) — показываем подсказку что нужно сделать

### Перевод слов — глобальная функция

**На любом английском слове во всех режимах Практики** работает долгое нажатие:
зажал слово → облачко (как в комиксах) с переводом и транскрипцией → кнопка "В мои слова" → экран с галочками: выбираешь нужные переводы → слово летит в Words8r в категорию **"МОИ СЛОВА"**.

Самые ходовые переводы идут первыми. Повторное зажатие того же слова — мгновенно из кэша.
Подробно: grammar8r_plan.md → «Работа со словами — перевод по тапу».

## Режим: Упражнения из теории

Дерево всех тем и микротем — как в разделе Теория, но только AI-упражнения. Пользователь выбирает конкретную карточку и запускает её AI-упражнение без необходимости идти в теорию и листать карточки.

**Структура дерева:**
```
Упражнения из теории
├── Present Simple
│   ├── Образование: утверждение    → [AI-упражнение: "Составь предложение"]
│   ├── Образование: отрицание      → [AI-упражнение: "Добавь отрицание"]
│   ├── Образование: вопрос         → [AI-упражнение: "Составь вопрос"]
│   ├── Употребление                → [AI-упражнение: "Переведи предложение"]
│   └── Маркеры времени             → [AI-упражнение: "Выбери маркер"]
├── Present Perfect
│   └── ...
└── ...
```

Каждая карточка в дереве показывает:
- Название карточки (из `GrammarCard.title`)
- Название AI-упражнения (из `AiExercise.title`)
- Иконка "выполнено" если у этой карточки есть хотя бы одна запись в `UserCardAiStats`

**Нажатие на карточку:**
1. Показывается `userInstruction` — что делать
2. Кнопка [Получить задание] → AI генерирует задание по `promptTemplate` + `theorySummary` карточки
3. Пользователь отвечает → фидбек → [Ещё задание] / [Назад к дереву]

**Важно:** `theorySummary` карточки всегда передаётся в промт — даже если пользователь пришёл из Практики и не читал теорию. Так AI понимает какое правило тренируем.

**Поиск:** дерево поддерживает поиск по названиям тем, микротем и `AiExercise.title`. Логика поиска — как в разделе Теория.

## Режим: Структуры времён

**Категория из 3 упражнений.** Пользователь выбирает какие времена он знает — именно они становятся вариантами ответов. Сложность растёт органически: чем больше тем выбрано, тем труднее угадать.

**Минимальное условие:** выбрано не менее 3 времён. Если меньше — кнопка неактивна с подсказкой "Выбери минимум 3 времени чтобы задание имело смысл".

**Удобно как разминка** перед более сложными режимами — быстро проверить структуру без перевода целых предложений.

### Упражнение 1: Схема + предложение → определи время

AI генерирует предложение и отображает его в виде таблицы-схемы:

```
She      │ has      │ visited  │ Paris
Subject  │ Auxiliary│ Verb(V3) │ Object
Подлеж.  │ Вспом.гл.│ Глагол   │ Дополнен.
─────────────────────────────────────────
Она      │ [имеет]  │ посетила │ Париж
```

Под таблицей — варианты ответов (именно те времена что пользователь отметил):
`[ Present Perfect ]  [ Past Simple ]  [ Present Continuous ]  [ Past Perfect ]`

**После ответа:** показывается что именно в схеме указывало на это время.
- Правильный ответ: "Верно! `has + V3` — маркер Present Perfect. Вспомогательный `has` показывает связь с настоящим моментом."
- Неправильный ответ: "Нет. Это Present Perfect: `has + V3`. В Past Simple вспомогательного глагола нет — `She visited Paris.`"

**Требования к AI при генерации:**
- Пример ОБЯЗАН быть однозначным — содержать уникальный маркер времени (auxiliary, -ing, -ed, V3)
- Нельзя давать `Subject + Verb + Object` без auxiliary — такая схема одинакова для Present Simple и Past Simple
- Слова в предложениях берутся из Words8r пользователя + базовая лексика предтемы
- На каждый запрос генерируется 1 предложение

**Формат ответа AI:**
```json
{
  "sentence": "She has visited Paris.",
  "schema": {
    "words": ["She", "has", "visited", "Paris"],
    "enLabels": ["Subject", "Auxiliary", "Verb(V3)", "Object"],
    "ruLabels": ["Подлеж.", "Вспом.гл.", "Глагол", "Дополнен."],
    "ruLiteral": ["Она", "[имеет]", "посетила", "Париж"]
  },
  "correctTense": "Present Perfect",
  "markerExplanation": "has + V3 — маркер Present Perfect. Вспомогательный has показывает связь с настоящим моментом.",
  "wrongAnswerFeedback": {
    "Past Simple": "В Past Simple нет вспомогательного глагола: She visited Paris.",
    "Present Continuous": "Present Continuous требует is/are + V-ing: She is visiting Paris.",
    "Past Perfect": "Past Perfect использует had, не has: She had visited Paris."
  }
}
```

### Упражнение 2: Название времени + пример предложения из пройденных слов пользователя из words8r → выбери правильную схему

Показывается название времени **и живой пример предложения** — составленный из слов которые пользователь знает по Words8r. Пример помогает не угадывать схему абстрактно, а видеть как она выглядит в реальном предложении.

Например:

> **Present Perfect Continuous**
> *"Katya has been studying English for two years."*
> *(Катя учит английский уже два года.)*

Под ним — 4 схемы (одна правильная, три похожих но неверных):

```
A)  Subject + have/has + V3 + Object
B)  Subject + have/has + been + Verb-ing + Object    ← правильная
C)  Subject + was/were + Verb-ing + Object
D)  Subject + had + V3 + Object
```

Пользователь выбирает правильную схему (A/B/C/D).

**Как AI генерирует пример:** берёт слова из Words8r пользователя (qRep > 0) и составляет короткое предложение в нужном времени. Предложение показывается вместе с русским переводом — чтобы было понятно о чём речь, даже если слово незнакомо.

**Дистракторы** генерируются из схем смежных времён — тех, что пользователь тоже отметил как известные. Чем больше выбрано тем — тем хитрее дистракторы.

**После ответа:**
- Правильный ответ: "Верно! Present Perfect Continuous = `have/has been + Verb-ing`. been — мост между present perfect и continuous."
- Неправильный ответ: объяснение чем отличается выбранная схема от правильной.

**Формат ответа AI:**
```json
{
  "targetTense": "Present Perfect Continuous",
  "correctSchema": "Subject + have/has + been + Verb-ing + Object",
  "correctIndex": 1,
  "schemas": [
    "Subject + have/has + V3 + Object",
    "Subject + have/has + been + Verb-ing + Object",
    "Subject + was/were + Verb-ing + Object",
    "Subject + had + V3 + Object"
  ],
  "explanation": "Present Perfect Continuous = have/has been + Verb-ing. been — мост между perfect и continuous.",
  "wrongAnswerFeedback": {
    "0": "Это схема Present Perfect: have/has + V3. Нет been и нет -ing.",
    "2": "Это схема Past Continuous: was/were + Verb-ing. Нет have/has.",
    "3": "Это схема Past Perfect: had + V3. Нет been и нет -ing."
  }
}
```

### Упражнение 3: Схема с пропуском из слов, которые знает пользователь из words8r → вставь слово

AI генерирует предложение из слов которые пользователь знает по Words8r (qRep > 0) — одно слово убирается в пропуск. Пользователь видит знакомые слова и фокусируется только на грамматике, а не на значении.

Показывается предложение-таблица с одним пустым слотом. Русской строки перевода нет — слова берутся из Words8r пользователя, он их знает. Если какое-то слово забыл — зажать и удерживать → всплывает маленькое облачко (как в комиксах) с переводом этого слова. Отпустил — облачко закрылось, продолжаешь.

Пример — тип «вспомогательный глагол»:

```
Igor     │  ___     │ cooked   │ dinner   │ yesterday
Subject  │    ?     │ Verb     │ Object   │ Time
Подлеж.  │    ?     │ Глагол   │ Дополнен.│ Время
```

Варианты: `has` / `had` / `—` (без вспомогательного) / `was`

Правильный ответ: `—` (Past Simple не требует вспомогательного глагола)

Пример — тип «форма глагола»:

```
She      │ has      │  ___     │ this book│ already
Subject  │ Auxiliary│    ?     │ Object   │ Adverb
Подлеж.  │ Вспом.гл.│    ?     │ Дополнен.│ Наречие
```

Варианты: `read` / `reads` / `reading` / `readed`

Правильный ответ: `read` (V3 неправильного глагола — форма совпадает с V1)

**Долгое нажатие на любое слово в таблице** → всплывающее облачко с переводом (comic speech bubble). Работает на всех словах кроме пропуска. Закрывается при отпускании пальца.

Пользователь выбирает из вариантов или вписывает сам (режим зависит от настроек).

**Два типа пропуска:**

1. **Вспомогательный глагол:** `She ___ visited Paris last year.` → `had` (Past Perfect с контекстом)
2. **Форма основного глагола:** `She has ___ (visit) Paris.` → пользователь вписывает `visited`

**После ответа:**
- Объяснение почему именно это слово
- Показывается полная схема без пропуска

**Формат ответа AI:**
```json
{
  "sentence": "She had visited Paris before she moved there.",
  "gapIndex": 1,
  "gapType": "auxiliary",
  "schema": {
    "words": ["She", "___", "visited", "Paris", "before she moved there"],
    "enLabels": ["Subject", "?", "Verb", "Object", "Time clause"],
    "ruLabels": ["Подлеж.", "?", "Глагол", "Дополнен.", "Придат.вр."]
  },
  "options": ["has", "had", "was", "—"],
  "correctOption": "had",
  "tense": "Past Perfect",
  "explanation": "Здесь Past Perfect: действие (посетила) произошло ДО другого действия в прошлом (переехала). Вспомогательный — had.",
  "wrongAnswerFeedback": {
    "has": "has + V3 = Present Perfect — связь с настоящим. Но тут два прошлых события, нужен had.",
    "was": "was + V3 не существует как грамматическая форма. was используется в Passive или Past Continuous (was + -ing).",
    "—": "Без вспомогательного получится Past Simple: She visited Paris. Но нам нужно показать что это произошло ДО переезда — для этого нужен had."
  }
}
```

## Режим: Перевод по пройденным темам *(основной режим практики)*

Главный режим вкладки. Объединяет пройденные темы + слова из Words8r.

**Старт сессии — настройки:**
1. Какие слова включать: `[Новые (qRep 1–8)]` / `[Хорошо изученные (qRep 9+)]`
2. Как переводить: `[Расставить слова]` / `[Ввести с клавиатуры]`

**Минимальное условие:** 50 слов в Words8r с qRep > 0. Если меньше — подсказка "Добавь слова в Words8r".

**Поток:**
- AI получает пройденные темы пользователя + выборку ~100 слов по алгоритму выборки
- AI генерирует RU предложение, использующее грамматику из пройденных тем + слова пользователя
- Режим расстановки: правильные слова + ловушки-дистракторы (неверная форма, не тот предлог, лишнее слово)
- Режим ввода: пользователь пишет с клавиатуры → AI проверяет → score + фидбек

**Ловушки в режиме расстановки:**
AI добавляет дистракторы: неверная форма глагола (visited vs visit), не тот предлог (in vs on), слово с неправильным окончанием (goes vs go). Пользователь выбирает правильный вариант, а не просто узнаёт слово.

**Формат ответа AI (ввод с клавиатуры):**
```json
{
  "score": 85,
  "correctedAnswer": "She doesn't like coffee.",
  "feedback": "Структура верная, но: 'don't' → 'doesn't' для she/he/it.",
  "errors": ["don't → doesn't (3-е лицо ед.ч.)"]
}
```

## Режим: Найди все ошибки

Дан абзац (2–4 предложения) с 3–5 грамматическими ошибками. Пользователь тапает на неправильные слова/формы.

**Правила генерации:**
- Ошибки только на правила из пройденных тем — нечестно ошибаться на неизученное
- AI заранее готовит список ошибок и объяснение каждой — не генерирует фидбек после ответа, а возвращает заранее
- Использует алгоритм выборки слов из Words8r

**Поток:**
1. Показывается абзац
2. Пользователь тапает на слова которые считает ошибочными
3. Кнопка "Проверить" (можно нажать до 3 раз)
4. После каждой неудачной попытки подсвечиваются ошибки которые нашёл vs пропустил
5. После 3-й неудачной попытки — подсвечиваются все ошибки + фидбек по каждой

**Формат ответа AI:**
```json
{
  "text": "She go to work every day. Yesterday she have lunch with her boss. They was talking about new project.",
  "errors": [
    { "word": "go", "position": 1, "correction": "goes", "explanation": "She — 3-е лицо ед.ч., нужно goes." },
    { "word": "have", "position": 9, "correction": "had", "explanation": "Yesterday — маркер Past Simple, нужно had." },
    { "word": "was", "position": 14, "correction": "were", "explanation": "They — множественное число, нужно were." }
  ]
}
```

## Режим: Заполни форму глагола

Дано русское предложение и его английский перевод, в котором один глагол стоит в скобках в форме V1. Пользователь вписывает правильную форму (регистр не важен, несколько правильных вариантов поддерживаются). AI генерирует предложения — расходует 1 запрос из дневного лимита.

**Пример:**
```
RU: Он пришёл домой поздно.
EN: He (come) home late.
Ввод: [ __________ ]
```
Правильный ответ: `came`

**Откуда берутся глаголы:** AI использует только глаголы из категории "Verb Forms" в Words8r у которых qRep > 0 (пользователь уже начал учить). Это гарантирует что в упражнении только знакомые слова, а не случайные.

**Минимальное условие:** хотя бы 10 глаголов с qRep > 0 в категории "Verb Forms". Если меньше — показываем подсказку (см. ниже).

---

**⚠️ Связь с темой «Глаголы V1/V2/V3» в теории**

После прохождения темы «Глаголы V1/V2/V3» приложение предлагает слить ~200 неправильных глаголов в Words8r (категория "Verb Forms"). В этот момент показываем **жирное предупреждение прямо на экране синка:**

> **⚠️ ОБЯЗАТЕЛЬНО добавь эти глаголы в Words8r!**
> Без них режим «Заполни форму глагола» во вкладке «Практика» работать не будет — там используются только слова из твоего словаря.

После того как пользователь добавил слова — сохраняем флаг `verb_forms_synced = true`.

Если пользователь попытался открыть режим при `verb_forms_synced = false` (или меньше 10 глаголов с qRep > 0) — показываем:
> "Для этого режима нужны глаголы из категории 'Verb Forms' в Words8r. Пройди тему «Глаголы V1/V2/V3» и добавь глаголы в словарь."
> Кнопка: [Перейти к теме]

Тема пересекается с режимом изучения форм неправильных глаголов в Words8r (см. words8r_plan.md).

## Режим: До/После (проверь свой текст)

Пользователь вводит любой английский текст → AI исправляет все ошибки разом.

- Свободный ввод, лимит ~500 символов
- Не привязан к словам из Words8r — свободный режим
- 3 AI-запрос из дневного лимита (указать, что расходуется 3 поинта дневного лимита )

**AI возвращает:**
```json
{
  "correctedText": "She doesn't like coffee.",
  "errors": [
    { "original": "don't", "correction": "doesn't", "explanation": "She — 3-е лицо ед.ч." }
  ]
}
```

**UX:** два режима отображения результата:
1. Исправленный текст с подсветкой изменений (было → стало)
2. Список всех ошибок с объяснением каждой

## Режим: Перевод рассказа

AI генерирует английский рассказ из слов пользователя. Пользователь переводит его на русский предложение за предложением.

Расходует **3 запроса из дневного лимита** — режим тяжёлый, генерирует длинный текст и проверяет каждое предложение. Показываем пользователю предупреждение перед стартом: "Этот режим использует 3 запроса из твоего дневного лимита."

**Настройки:**
- Длина рассказа: 10–20 / 20–50 / 50–100+ слов
- В рассказ подмешиваются незнакомые слова — визуально выделены
- Нажатие на любое слово → перевод через LingvoLive/Yandex Dictionary

**Поток:**
1. AI генерирует рассказ целиком и сразу
2. Вверху экрана — кнопка **"Показать весь текст"**: раскрывает полный рассказ одним блоком (на случай если пользователь хочет сначала пробежать глазами). Закрывается обратно.
3. Предложения показываются по одному — пользователь переводит каждое
4. Пользователь вводит русский перевод
5. AI проверяет → фидбек → следующее предложение
6. По ходу строится итоговая страница: EN сверху, перевод пользователя снизу

**4 режима просмотра финала:**
- Только английский оригинал
- Только перевод пользователя
- EN + перевод пользователя
- EN + эталонный перевод от AI

**Сводка:** все замечания AI по рассказу в одном месте после завершения.

## Режим: Разговорный английский

Доступен после прохождения темы «Разговорный английский» в теории.
Слова берутся из Words8r, категория "Informal English" (только изученные пользователем).
Минимум для старта: 5 изученных разговорных слов.

**Два подрежима:**

**Формальное → Разговорное:** AI генерирует формальное предложение используя слова из Words8r → пользователь заменяет формальные части на разговорные.
Пример: "I am going to call you later." → "I'm gonna call ya later."

**Разговорное → Формальное:** AI пишет неформальный текст (2–3 предложения) → пользователь переводит в формальный английский.

Оба подрежима = 1 AI-запрос из дневного лимита.
