## 🛡️ Admin — только для разработчика

Выдаётся вручную через панель администратора. Никаких ограничений ни по одному параметру.

- AI-запросов в день: **∞**
- Микротем в день: **∞**
- Стрик, заморозки, лимиты — не применяются
- Бан/suspend — не применяются
- Срок: бессрочно если поле `expires_at` не заполнено, иначе до указанной даты

На сервере в потоке каждого запроса: если `tier = "admin"` → пропустить все проверки лимитов, не инкрементировать счётчики.

## 🧪 Tester

Выдаётся вручную тестерам через панель администратора. Тир единый для всех тестеров — лимиты настраиваются глобально на сервере (не индивидуально).

- Лимиты: равны Tier 1 по умолчанию, но могут быть изменены в любой момент через серверный конфиг без релиза
- Срок: бессрочно если поле `expires_at` не заполнено, иначе до указанной даты
- Стрик, заморозки — применяются как у Tier 1

На сервере: `tier = "tester"` → брать лимиты из таблицы `subscription_limits` для строки `tester`.

## Платные функции Words8r

### Режим Wordly — кнопка-подсказка «скрыть лишние буквы»

Кнопка в TopBar экрана `WordlyScreen`. Видна всем, но работает только по подписке.

**Что делает:** случайно скрывает 20% букв, которых нет в загаданном слове — отображает их серым (как Absent), будто уже проверены. Применяется один раз за текущую игру.

**Кулдаун:** зависит от тира подписки. Счётчик `wordly_hint_cooldown_remaining` в SharedPreferences, декрементируется после каждой игры, восстанавливается до значения тира после использования подсказки.

| Тир | Кулдаун |
|-----|---------|
| Tier 1 | 1 раз в 3 сыгранные игры |
| Tier 2 | 1 раз в 2 сыгранные игры |

| Сценарий | Реакция |
|----------|---------|
| Без подписки | Snackbar: «Доступно только по подписке» |
| Подписчик, кулдаун не истёк | Snackbar: «Станет доступно после N игр» |
| Подписчик, кулдаун истёк | 20% absent-букв скрываются, кнопка деактивируется до следующей игры |

**Статус реализации:** кнопка, кулдаун, Snackbar и логика `computeHiddenKeys()` реализованы с хардкодным `isSubscriber = false`. При добавлении подписки — переключить на реальную проверку.

## Единая подписка: Grammar8r + Words8r

Подписка общая для обоих приложений. Купил в одном — работает в другом.

### Лимиты Words8r (без подписки / Free)

| Действие | Free | Tier 1 / Tier 2 |
|----------|------|-----------------|
| Новые слова/день | 10 | без лимита |
| Повторения/день | 50 | без лимита |
| Режим соответствия/день | 3 | без лимита |

Лимиты мягкие — обычный пользователь (5 слов/день + повторения) их не достигнет. Цель: не мешать, но дать причину подписаться при активном использовании.

### Офлайн-логика проверки подписки в Words8r

Words8r работает без интернета — статус подписки кэшируется локально:

1. Первый запуск за день → запрос к серверу. Успешно → кэшируем.
2. Ни разу не было ответа сервера → бесплатные лимиты.
3. Кэш есть + нет интернета → доверяем кэшу (подписка могла истечь — потери минимальны).
4. Нет интернета > 7 дней → баннер *"Не удалось проверить подписку — установлены бесплатные лимиты"*. Пропадает при следующем успешном ответе сервера.

Константа grace period (`SUBSCRIPTION_GRACE_PERIOD`) — в одном месте. Дебаг = 10 минут, прод = 7 дней.

## Лимиты и сброс

- Сброс AI-лимита и лимита микротем: ежедневно в **00:00 МСК (UTC+3)**
- Отслеживается на сервере — смена часового пояса на телефоне не помогает
- Заморозки стрика: сбрасываются в начале каждого календарного месяца, не накапливаются

## Что считается за AI-запрос (−1 от лимита)

- Умное упражнение в конце карточки
- Уточняющий вопрос "Не совсем понял" (каждый вопрос, включая "Ещё вопрос")
- Любой режим практики с AI (перевод по темам, рассказ, найди ошибки, до/после)

Не считается: хардкодные упражнения, чтение теории, перевод слов по тапу.

## Стрик — механика

**Стрик общий для Grammar8r и Words8r.** Засчитывается действие в любом из приложений.

**Что считается за день:**
- Grammar8r: минимум 1 AI-задание (любое)
- Words8r: завершена сессия повторения / игра Wordly / игра Maze / выучено 5 новых слов

Просто открыть приложение — не считается. Нужно завершить действие.

- Отсчёт дня по МСК, сброс в 00:00 МСК
- Пропустил день → стрик сбрасывается, все бонусные запросы Grammar8r сгорают
- Бонусы milestone — только в Grammar8r (Words8r AI не использует)
- Если milestone достигнут в Words8r, а Grammar8r не установлен → бонусы ждут на сервере, активируются при установке
- Объясняется при онбординге обоих приложений

**Заморозка:** ручная активация из любого приложения (подписка общая). При открытии после пропущенного дня:
*"Вчера не было занятия. Использовать заморозку? (Осталось: N)"*

**Offline-синк:** стрик хранится локально + на сервере. Дата действия определяется в момент выполнения по MSK. При появлении сети — синк на сервер. Сервер авторитет при конфликте.

## Расчёт расходов (DeepSeek-V4.1-Flash, курс ~90₽/$)

> ⚠️ Это оценка до тестов на сервере. Точный расход токенов покажут первые реальные запросы —
> тогда цифры уточняются, а лимиты правятся в таблице `subscription_limits` без релиза приложения.

### Модель и цена

Модель — **`deepseek-flash` (DeepSeek-V4.1-Flash)**: актуальная (не старая) и самая дешёвая модель
DeepSeek, её хватает на наши задания — перевод короткой фразы и разбор по готовым правилам. Старшая
`deepseek-v4-pro` дороже примерно в 4,4 раза и нам не нужна.

Цена за 1 млн токенов ([страница цен DeepSeek](https://api-docs.deepseek.com/quick_start/pricing)):

| deepseek-flash | Пик | Вне пика |
|---|---|---|
| Вход, повтор из кэша | $0,006 | $0,003 |
| Вход, новый | $0,30 | $0,15 |
| Выход | $1,20 | $0,60 |

Пиковые часы — 04:00–07:00 и 09:00–13:00 по Москве, по будням. Всё остальное время, включая выходные,
вдвое дешевле. Расчёт ниже — по пиковой цене, то есть с запасом.

### Из чего состоит одно обращение к ИИ

| Часть запроса | Токенов |
|---|---|
| Базовый промт (блоки «Роль», «Знает базу», «Обратная связь», «Поведение» — `ai_base_prompt.md`) | ~1 000–1 200 |
| Промт карточки (у свежих тем 4–7 тыс. символов) | ~1 500–3 000 |
| Слова пользователя (только на генерации задания) | ~400 |
| Текст задания и ответ пользователя (только на оценке) | ~200 |
| **Итого на вход** | **~4 000–5 000** |
| **На выход** (задание или разбор ответа) | **~300–700** |

Потолок длины ответа ставим ~800 токенов: разбор ошибки с «что значила бы ваша фраза» в 300 не влезает.

### Цена одного обращения

Считаем 4 500 токенов на вход и 500 на выход:

| Сценарий | Вход | Выход | Итого | В рублях |
|---|---|---|---|---|
| Без кэша (худший) | $0,00135 | $0,0006 | $0,00195 | ~0,18₽ |
| С кэшем (реальный) | $0,0003 | $0,0006 | $0,0009 | ~0,08₽ |
| **Расчётная цена, с запасом** | | | | **0,12₽** |

**Кэш.** DeepSeek сам кэширует одинаковое начало запроса и берёт за него почти ничего. Базовый промт и
промт карточки одинаковы у всех, кто делает это задание, — это ~3 500 из 4 500 токенов. Условие одно:
**сервер собирает запрос так, чтобы неизменное шло первым** — базовый промт → промт карточки → и только
потом то, что меняется (слова пользователя, задание, ответ). Это правило обязательно для Фазы 4.

### Главная формула

Одно обращение ≈ 0,12₽. Если человек тратит **1 запрос каждый день месяца**, это 30 × 0,12 ≈ **3,6₽**.

> **Расход на человека в месяц (худший случай) = лимит в день × 3,6₽**

Худший случай — человек выбирает весь лимит каждый день месяца, все 30 дней подряд.

> ⚠️ Единица лимита = **одно обращение к ИИ** (одно сообщение ИИ) — так пользователю сказано в теории
> курса. Одно задание с ИИ — это минимум 2 обращения: выдать задание и проверить ответ. Если решим, что
> единица лимита — это всё задание целиком, расход на единицу удваивается и расчёт надо пересчитать.

### Тиры: грязная маржа (цена подписки − расходы на ИИ)

Без комиссии магазина или платёжки и без налога.

| Тир | Цена | Лимит/день | Худший случай: расход → маржа | Макс. стрик, худший: расход → маржа | Реальный (~40% лимита): расход → маржа |
|---|---|---|---|---|---|
| **Free** | 0₽ | 5 (до 7 со стриком) | 18₽ → **−18₽** | 25₽ → **−25₽** | единицы рублей |
| **Tier 1** | 179₽ | 20 (до 28) | 72₽ → **+107₽** | 101₽ → **+78₽** | ~32₽ → **~+147₽** |
| **Tier 2** | 249₽ | 35 (до 47) | 126₽ → **+123₽** | 169₽ → **+80₽** | ~55₽ → **~+194₽** |

- Даже в самом плохом раскладе — весь лимит каждый день плюс стрик 100+ дней — маржа платных тиров
  около +80₽. **В минус подписчик уйти не может.**
- Самый плохой сценарий на практике почти не встречается: он требует и 100% лимита каждый день, и стрика
  в 100 дней одновременно. Реальное потребление — ~30–50% лимита.
- Free: худший бесплатник стоит ~18–25₽ в месяц, обычный — единицы рублей (большинство заходит редко).
  **Один подписчик Tier 1 покрывает ~4–6 бесплатников**, которые выжимают лимит до конца.

**Почему Tier 2 выглядит выгоднее.** Всего на 70₽ дороже — и в 1,75 раза больше запросов. Цена одного
запроса: у Tier 1 ~0,30₽, у Tier 2 ~0,24₽. Tier 1 = 20 в день — обычная норма активного ученика
(~10 заданий с ИИ); кому мало — естественный повод перейти на Tier 2.

### Стрик — почему в минус уйти нельзя

| Дней подряд | Free (база 5) | Tier 1 (база 20) | Tier 2 (база 35) |
|---|---|---|---|
| 7 | +1 → 6 | +1 → 21 | +2 → 37 |
| 20 | — | +2 → 22 | +4 → 39 |
| 30 | +2 → 7 (макс.) | +4 → 24 | +6 → 41 |
| 60 | — | +6 → 26 | +9 → 44 |
| 100 | — | +8 → **28** (макс.) | +12 → **47** (макс.) |

Максимальный стрик при 100% использовании: Tier 1 — 28 × 3,6 = 101₽ (маржа +78₽), Tier 2 —
47 × 3,6 = 169₽ (маржа +80₽). Бонус приятный, но разорить не может.

### На руки: платёжка и налог

**Оплата через ЮKassa на своём сайте** (для самозанятых подключение бесплатное, платишь только комиссию
с платежа; автоплатежи для подписок поддерживаются):

| Способ оплаты | Комиссия ЮKassa |
|---|---|
| Банковская карта (МИР, Visa, Mastercard) | ~3,5% |
| СБП | от 0,4%, но не больше 1 500₽ с платежа |
| ЮMoney, SberPay, T-Pay | ~3,5–3,8% |

**Налог самозанятого (НПД) в 2026:**
- **4%** — когда платит физлицо (наш случай при оплате через ЮKassa);
- **6%** — когда платит компания или ИП (случай магазина приложений: деньги перечисляет не человек, а магазин);
- при регистрации бонус 10 000₽ — пока не кончится, ставка ниже: 4% → 3%, 6% → 4%;
- лимит — 2,4 млн₽ дохода в год (при цене Tier 1 это ~1 100 оплат в месяц), дальше нужен ИП;
- режим НПД продлён до конца 2028 года.

**Остаток на руки через ЮKassa по карте** (3,5% + 4% налога ≈ 7,5%):

| | Tier 1 (179₽) | Tier 2 (249₽) |
|---|---|---|
| После комиссии и налога | ~165₽ | ~230₽ |
| Реальный случай (минус ~32 / ~55₽ на ИИ) | **~133₽** | **~175₽** |
| Худший случай (минус 101 / 169₽ на ИИ) | ~64₽ | ~61₽ |

Через СБП комиссия почти нулевая — ещё +5–8₽ с подписки.

**Для сравнения — через магазин приложений** (~15% магазину + 6% налога ≈ 21%): остаётся ~141₽ с Tier 1
и ~197₽ с Tier 2; в реальном случае на руки ~109₽ и ~142₽, в худшем ~40₽ и ~28₽. Своя оплата через
ЮKassa даёт примерно на 25–30₽ больше с каждой подписки.

> Ставки ЮKassa взяты из обзора на vc.ru (официальная страница тарифов не открылась) и могут зависеть
> от категории бизнеса — перед подключением сверить на [yookassa.ru/fees](https://yookassa.ru/fees/).
> Правила Google Play и RuStore о продаже подписки в обход их оплаты для России — проверить отдельно
> перед запуском (покупка на сайте + только вход в приложении — см. «Платёжные каналы по площадкам» ниже).

### Что не вошло в расчёт

- **Сервер и хостинг** — фиксированная сумма в месяц (Beget VPS 2 040 ₽ + копейки за хранилище бэкапов),
  делится на всех: на 1 000 пользователей это ~2 ₽ на человека, окупается ~15–20 подписчиками.
- **Бесплатники** — их расход покрывают подписчики (см. выше).
- **Словарь** (LingvoLive / Yandex Dictionary) — кэшируется, но тоже может стоить денег.

### Как держать расходы низкими

1. **Кэш** — неизменная часть запроса первой (см. «Цена одного обращения»). Самый сильный рычаг.
2. **Промты без воды** — каждый символ промта уходит в каждый запрос (канон — `theory_content_guide.md` §5).
3. **Потолок ответа** ~800 токенов.
4. **Внепиковое время** — вечер, ночь и выходные по Москве в два раза дешевле.
5. Хардкодные упражнения ИИ не используют вообще.

**Яндекс OAuth**
- Быстрый вход через Яндекс аккаунт (есть у большинства RU-пользователей)
- SDK для Android от Яндекса
- Uid берётся из Яндекса

**Собственная регистрация (email + пароль)**
- Для тех кто не хочет через Яндекс
- Email + пароль → сервер выдаёт uid + JWT-токен
- Сброс пароля через email

Оба способа дают одинаковый uid в системе подписок. Хранение паролей — bcrypt-хэш на сервере, в открытом виде никогда.

### ⚠️ Платёжные каналы по площадкам — пометка на будущее

**Сейчас релиз только в RuStore**, где YooKassa работает прямо в приложении без ограничений.
Всё ниже — на будущее, чтобы не загнать модель подписки в угол. По факту выхода на другие
площадки — решать тогда, перепроверив актуальные правила.

Ни Google Play Billing, ни Apple IAP не принимают платежи от российских пользователей (оба
отключены с 2022). Значит для Play- и iOS-сборок оплата внутри приложения недоступна в принципе,
и универсальный путь один: **оплата на нашем сайте под тем же аккаунтом**, что и в приложении.
Пользователь оплатил на сайте → зашёл в приложение → подписка есть. Внутриприложенческая оплата
через YooKassa — не отдельная система, а удобное дополнение поверх этой же модели для RuStore.

Что из этого следует для дизайна подписки:

- **Модель в БД — сущность «платёж», а не поле «оплачено до».** Источников минимум четыре:
  YooKassa из приложения, YooKassa с сайта, возможный Apple IAP, ручная выдача через админку.
  У каждого — свой источник и внешний ID (защита от двойного зачисления: оплатить дважды с разных
  устройств реально). Состояние подписки аккаунта **вычисляется** из платежей.
- **Права приходят «снаружи».** Оплата на сайте происходит мимо приложения, поэтому нужен явный
  механизм обновления: перечитывать `GET /subscription` при возврате в приложение + кнопка
  «Я оплатил, обновить» на экране подписки.
- **Экран оплаты — серверный.** Сервер говорит, какой способ оплаты показать (YooKassa в
  приложении / ссылка на сайт / ничего). Смена правил площадки — правка на сервере, а не релиз
  с прохождением ревью. В Play-сборке платёжный UI отсутствует полностью: риск там исходит от
  стиринга (кнопки «Купить», ценники), а не от самого факта внешней оплаты.
- **Аккаунт нужен раньше денег** — логин на сайте и в приложении один и тот же.

Подробный разбор с обоснованием — `ios_portability_plan.md` §8.5.

### Эндпоинты подписки

**`GET /tier-limits`** — публичный, без авторизации.
Возвращает лимиты всех тиров (free, t1, t2, tester). Используется на маркетинговом экране подписки.
Клиент запрашивает при открытии экрана и кэширует. Оффлайн — показывает кэш.

**`GET /subscription`** — приватный, с JWT-токеном.
Возвращает персональные данные пользователя: `{ tier, expires, aiRequestsToday, aiDailyLimit, microtopicsToday, microtopicsDailyLimit }`.
Используется на экране "Моя подписка" для отображения остатка лимитов.

### Хранение лимитов на сервере

Лимиты хранятся в таблице БД `subscription_limits(tier, ai_per_day, microtopics_per_day)`.
При изменении строки в БД новые лимиты вступают в силу в течение ~5 минут (серверный кэш с TTL).
Рестарт сервера не нужен.

**Текущие значения лимитов** (записаны в `subscription_limits`, могут меняться без релиза):
- Free: 5 AI/день, 2–4 микротемы/день
- Tier 1: 20 AI/день, без лимита микротем
- Tier 2: 35 AI/день, без лимита микротем
- Tester: по умолчанию как Tier 1, настраивается

В клиентском приложении на маркетинговом экране — числа подтягиваются с `/tier-limits`.
При отсутствии сети — показывается кэш или общее описание без конкретных цифр.

## Условия подписки и правовая база

### Принятие условий перед покупкой

Перед оплатой пользователь обязан поставить галочку:
> "Я принимаю [Условия использования] и [Политику конфиденциальности]"

Без галочки кнопка "Оплатить" неактивна. Ссылки ведут на страницы мини-сайта на нашем сервере.

### Ключевые пункты условий (войдут в документы)

- Подписка действует на **не более чем 3 устройства** одновременно. При превышении разработчик вправе применить санкции (аннулирование подписки или блокировка аккаунта).
- Разработчик вправе **в одностороннем порядке** расторгнуть договор (аннулировать подписку / заблокировать аккаунт) без объяснения причин.
- Пользователь вправе отменить подписку в любой момент самостоятельно.
- Персональные данные (email) хранятся в зашифрованном виде, не передаются третьим лицам. Пароли хранятся исключительно в виде bcrypt-хэша, восстановлению не подлежат.
- Апелляции по решениям администрации направлять на [email].

> ⚠️ **Напомнить при реализации:** попросить скинуть примеры файлов политики конфиденциальности и пользовательского соглашения для адаптации под проект.

### Экран "Мой профиль" в приложении

Отдельный пункт в меню обоих приложений (Grammar8r и Words8r). Показывает:

- Текущий тир подписки

- Кнопка "Продлить подписку" → экран подписки с тирами
- Кнопка "Выйти из аккаунта"
